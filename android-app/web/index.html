Open a schematic, PCB or project file. Open a folder to include nested sheets and local 3D models.

Phone and tablet layouts share the same viewer.

Read-only local, GitHub and GitLab viewing. Review drafts stay on this device. Publish to share them on GitHub or GitLab.

GitHub projects

Private OAuth access requests GitHub’s broad read/write repo scope. GitHub may require organization approval or SSO. Public sign-in requests public_repo for review publishing. Credentials stay in Android’s protected storage.

Use a restricted token instead

For narrower access, create a fine-grained GitHub token for selected repositories with Contents: Read-only. Enter it only in the Android password dialog.

Saved projects

Saved entries contain a repository link and revision, not downloaded source. Reopening refreshes from GitHub. Publish saved review notes from the drawing’s Comments pane.

GitLab projects

Tokens are entered in Android’s protected dialog. Use read_api to browse; api is needed to publish reviews.

GitLab account sign-in

Register a non-confidential OAuth application on this server with api scope and redirect URI kicadvizdiff://gitlab-oauth. Enter its public Application ID, never a secret.
