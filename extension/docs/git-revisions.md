# In-browser Git revisions

In the inline drawing header, open **Git revisions** → **Load branches + history**. Choose a branch or a commit touching the active file for each side, or enter a branch, tag or SHA manually. **Compare revisions** opens the existing browser schematic/PCB comparison and saved-object change inspector in the same extension frame. **View head** opens one selected revision. The repository is fixed to the original viewer context; fork comparisons keep separate base/head repositories and old/new paths.

Branch choices capture their returned commit SHA. Manual refs are resolved to SHA before either viewer opens. File history first resolves the starting ref, then requests commits for that immutable SHA and exact file path. History is limited to 50 commits and branch discovery to 100 names; pagination and full lists show warnings, with manual entry for omitted refs. GitHub history does not follow renamed files automatically; open the old path or use an existing rename comparison when needed. Refs at which the file is absent produce the drawing viewer's retrieval diagnostic.

Pull-request previews retain their existing GitHub merge-base and fork handling; the manual picker is intentionally absent from PR review. This feature is read-only: it does not checkout, commit, push, merge, or change repository files. Public repository browsing works without a token; existing extension sign-in credentials authenticate history requests inside the worker and are never passed to the picker. GitHub rate limits or access restrictions show errors. This is an extension viewer feature, not an embedded GitHub native UI capability or a full Git client.

Worker messages `revision-branches`, `revision-commits`, and `revision-resolve` are permitted only from exact trusted extension viewer pages. Repository, ref and drawing path are checked before requests; response text is bounded to 1 MiB, lists and hashes are validated, and returned labels use text nodes. Normal file preview navigation continues through the existing isolated extension frame and browser rendering engine.
