Share a drawing annotation
  1. In Comments, add a note to a part, a point or an area. Save it before sharing.
  2. Choose Issues for an actionable task or Discussions for a question or design conversation. Choose a new thread or enter an existing thread number.
  3. Return to the saved note and select Open GitHub composer to review and submit on GitHub, or Publish to GitHub to post with your configured account.
  4. Use @mentions in the note; follow replies and GitHub notifications in the linked thread.
Severity and review state describe the annotation, independently of its thread type. Saving, choosing a destination or loading annotations never posts a comment. Post to GitHub uploads a captured screenshot with the review when your account has repository write access. A failed upload keeps the draft. The manual composer still requires attaching the downloaded image yourself.
Load GitHub annotations reads supported revision-bound annotation markers, not every message in a thread. Marked Issue and Discussion comments can be loaded for this drawing. Use Reply to start a new anchored draft. Use View comments → Load thread to read ordinary messages and replies here. Subscriptions and closing issues remain on GitHub. A local resolved/skipped state does not close a GitHub thread.
