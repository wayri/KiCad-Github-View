# v0.12.26 — Saved net-class colors

Both drawing viewers have a **Net colors** toggle beside the review tools. It loads the matching saved .kicad_pro settings on demand and uses pcb_color in layout and schematic_color in schematics. If the settings association is ambiguous, choose a project file from the toolbar selector. The toggle preference is remembered per project/view.

Connected copper, schematic wires, junctions, pins and labels use the saved class colors. Unspecified/transparent colors retain normal theme/layer colors; class priority and Default fallback are respected. Selection highlights take precedence. Switching off restores the original drawing colors without modifying source geometry. WebGL motion previews inherit the same drawing colors. This is a 2D display option, not a 3D material setting.

Membership retains the existing bounded saved-assignment and wildcard support. Native regex/bus expressions, derived assignments and schematic netclass directives are not evaluated; unsupported memberships are reported rather than guessed. Colors are validated numeric RGBA/hex values; arbitrary CSS is not interpreted.

Validation includes class priority and transparency, PCB and schematic mapping, missing/ambiguous settings, restoring original colors, and highlight precedence. Browser checks use production viewer code with fixture transport. Private-repository and installed-browser acceptance are not implied. Firefox remains unsigned; Safari requires macOS conversion and signing.
