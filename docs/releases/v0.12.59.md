# Pocket KiView 0.12.59 / Android 1.61

This update adds cancellable loading and the KiCad Default layer palette to the
shared viewers. iPhone/iPad work remains excluded.

## Changes

- Stop repository reads, project discovery and drawing preparation. Cancelled
  results cannot reopen a stopped drawing; Retry starts a fresh load.
- Bound initial loading waits and terminate parsing workers on cancellation or
  timeout. Large drawings no longer silently use a blocking main-thread fallback.
- Preserve other views sharing a download and retain the active project and
  provider sign-in. Publishing, uploads and saved-library writes have no Stop.
- Use KiCad Default colours for PCB layers, recognized Gerber layer roles and
  3D copper, with distinct internal copper layers and mask/paste opacity.
- Prepare VS Code drawings in a bundled worker with a narrowly scoped resource
  policy. VS Code can stop preparation and waiting; its filesystem API cannot
  abort a host read already in progress.
- Android cancels scoped network/local reads and rejects late project delivery.

## Validation and limits

See docs/VALIDATION-2026-10-26.md for checks and acceptance scope. Stop was exercised
with an actual stalled local HTTP body and a busy worker, including retry. These
isolated checks do not establish live Git host or physical-phone acceptance.

Chrome Store and VS Code Marketplace publication are separate from local packages
and GitHub releases. Android APK 1.61/code64 is a development-signed preview; the
unsigned AAB requires distribution signing. Firefox and Safari retain their
development/signing limits.
