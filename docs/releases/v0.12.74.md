# Pocket KiVi 0.12.74 / Android 1.74

Adds detachable browser schematic, PCB layout and 3D viewer windows. Use the
Detach view menu or drag a supported view tab outside the viewer. Each window
has an independent camera. Cross-selection can be enabled or disabled for the
linked session. Messages are restricted to the same project and revision,
validated and bounded, and do not trigger selection echo loops.

The release retains experimental Fast PI, compact view navigation, corrected
selection outlines, Draftsman and saved simulation workflows from 0.12.73.
Browser and imported-local browser projects support detached windows. VS Code
Webviews and native Android WebViews currently retain split views and show an
explicit unsupported-window message; native OS floating windows are not claimed.
See docs/DETACHED-VIEWS.md for host limitations and local-workspace lifetime.

Android 1.74/code77 contains the shared viewer updates. It uses the existing
development signing channel. The unsigned AAB is not ready for Play upload.
Store approval is separate from GitHub publication. Numerical limits for
experimental Fast PI remain documented in docs/FAST-PI.md.
