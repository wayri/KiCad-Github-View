# Pocket KiView 0.12.61 / Android 1.63

This preview closes conversation and Git-browsing gaps across the clients and includes the improvements prepared since 0.12.58.

- Stop and retry long-running project loads, with cancellation propagated through supported host transports.
- Use KiCad Default colors for PCB layers and recognized Gerber roles.
- Refine Android controls, project file trees and spacing, plus flatter repository navigation across clients.

- Read GitLab issue bodies, ordinary comments and grouped discussion replies
  inside Chrome, Android and VS Code, with authors, dates and open/closed state.
- Restore Android collaboration controls for connected repository projects even
  when the shared local-source bridge is present. Offline imports keep local notes.
- VS Code can connect GitHub through its native account provider, read issue and
  Discussion threads, create issues/comments, and publish supported screenshots.
  GitLab credentials are entered only in a host password prompt and retained in
  VS Code SecretStorage for the exact Git remote host.
- Bind remote operations to a trusted workspace, Git remote and immutable commit.
  Compare raw committed bytes before pinned annotation publication/readback.
  Uncommitted-source mismatches block these operations; ordinary thread reads
  remain available.
- Browse historical Git file trees and open files in separate read-only commit
  viewers, including saved sheet/model dependencies. Working files are not replaced.
- Validate local GitLab publication receipts through an explicitly bound workspace
  validator; the default provider/host/project checks remain strict.

GitLab conversations belong to issues; standalone Discussion categories and merge
request publication are not supplied. A notification inbox and live conversation
sync remain unavailable. Historical VS Code viewers are read-only, including local
annotations and remote publishing. Native Git is required for historical files and
raw-source verification. Open a nested repository directly rather than through an
ancestor workspace folder.

See docs/VALIDATION-2026-10-26.md for evidence and live-account/device limits.
The VS Code Marketplace upload was accepted and is awaiting Microsoft verification. Chrome Web Store publication is separate. iPhone/iPad work remains excluded.

Android 1.63 is development-signed for manual installation; the unsigned AAB is not ready for Play upload. Ordinary live-account posting acceptance is not implied by automated transport tests.
