# v0.11.7 — browser development packages and illustrated integration guides

This prerelease adds an unsigned Firefox 128+ extension and a Safari 16.4+ macOS development payload. The Firefox package uses an event-page background and a Promise API adapter. Safari includes an Apple conversion helper; native Xcode conversion, signing and installed-browser acceptance require a Mac and have not been performed here. Neither package is a browser-store release.

Account settings now present **Sign in with GitHub** and **Sign out**, with client ID/token fields collapsed under Advanced. Users explicitly choose public or public/private access; scope validation and session-only token storage are tested. The publisher OAuth App registration/client ID is still required before device sign-in can work; no live authorization is claimed.

Firefox repository HTML is isolated and static; interactive iBOM is disabled. Safari repository HTML preview is disabled, with saved source still available. Review JSON import/export is available in both targets; automatic selected-file writes remain a Chromium feature. Shared schematic, PCB, project, 3D and comparison viewers are packaged from the same source inventory.

Separate illustrated GitHub and GitLab guides explain viewing, selection, navigation and review workflows. GitHub offers explicit Issue/Discussion publication; GitLab notes remain local/exportable with manual native issue creation. Seven new screenshots show actual local fixture UI with mocked repository metadata and transport; they do not claim live publication or installed-browser acceptance. A downloadable guides ZIP retains their images and documentation.

GitLab local notes now display a local-review heading instead of a GitHub Issue/Discussion label. Package inventories, deterministic archives, private settings resources and session-only credential behavior are checked before release.

GitHub navigation metadata must match the current full file path and revision, avoiding stale branch or same-basename entries in nested project folders. Linked 3D asset reads now use the configured extension token on the GitHub API, like drawing and project reads. HTTP 404 errors distinguish absent files from concealed private-repository access and identify the requested scope. Regression fixtures cover nested 2 MB boards, subsheet discovery, stale navigation and authenticated model/PCB reads. The reported private HPBM repository was not accessed; private pull-request comparison and private annotation readback remain unsupported.

Read-only engineering preview limits still apply: unsupported constructs and missing model assets are reported, and STEP model rendering is not supplied. Inspect critical geometry in native KiCad.
