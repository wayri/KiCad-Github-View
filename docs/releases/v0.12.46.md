# KiCad Visual Review 0.12.46 / Pocket KiView Android 1.58

This prerelease fixes the browser extension toolbar icon opening nothing.

- Clicking the icon or using Alt+Shift+K opens Pocket KiView's local workspace
  on ordinary tabs, repository home pages and tabs without an accessible URL.
- Supported drawing and review pages still focus their existing inline viewer.
  An unavailable content script or a viewer that cannot be focused opens the
  local workspace instead of silently doing nothing.
- GitLab drawing and merge-request pages use the same visible fallback. No new
  host permission or account connection is required for local files.
- If opening the workspace fails, the worker records the error and opens extension
  settings rather than swallowing the failure.

Reload the updated extension and refresh existing GitHub/GitLab tabs. Focused
background/content/GitLab tests and Firefox package checks passed during the fix;
live installed-browser toolbar acceptance remains pending.

Android remains 1.58/code61 because its runtime does not use this extension-only
worker. Its previously built binaries are accepted only if exact viewer payload,
version, signature and lint audits still match this source snapshot. The APK is
development-signed; the AAB is unsigned and requires upload signing before Play
submission. Browser-store and native Safari acceptance are separate. iPhone work
is excluded. Source commit and verified SHA-256 checksums accompany the release.
