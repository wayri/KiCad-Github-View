# v0.12.2 — Account button feedback

The main GitHub account button now switches from green **Sign in with GitHub** to red **Sign out of GitHub** when the extension holds a connected credential. Clicking the red button cancels pending authorization, clears credentials and restores the green sign-in action. The duplicate sign-out button is hidden.

This includes v0.12.1's background device-code polling, refresh on return from GitHub, account dot indicator, restart/expiry diagnostics and **Test repository access**. Use that read-only API check to verify access to a specific private repository; a stored credential alone is not proof of repository permissions. Temporary encryption keys still disappear on background restart, so reconnect after restart/reload.

The account-button regression verifies that the connected action clears authentication rather than starting another sign-in, and resets both its label and color state. Full shared release gates apply to all browser packages. Firefox remains unsigned and Safari requires macOS conversion/signing. Live private-repository acceptance remains dependent on testing the user's authorized account and repository.
