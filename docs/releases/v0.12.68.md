# Pocket KiView 0.12.68 / Android 1.70 — full-net 3D inspection

Selecting a net in the shared browser, VS Code and Android 3D viewer now reveals its saved copper across outer and internal layers. Display → Full net 3D is enabled by default; it temporarily reveals selected geometry even when ordinary layer/category filters hide it. The substrate, component models and other context become translucent grey. Clearing selection or disabling Full net 3D restores the original materials, instance colors and visibility settings.

- Render saved track/arc segments, pad copper, saved filled polygons and plated pad transitions at their layer depths. Unfilled zones remain outlines; no copper or routed connections are invented.
- Resolve through, blind, buried and microvia barrels from explicit source layer endpoints; reject ambiguous/unknown spans. Blind/buried vias no longer cut full-depth substrate holes.
- Use complete saved asymmetric stackups for copper elevations. Missing/inconsistent depths and copper thickness use explicitly labelled display estimates. Barrel plating wall thickness is illustrative (25 µm), while saved drill size and via spans are retained.
- Keep actual selected copper visible independently of the 2,000-object bounding-box limit. Batch geometry, reuse an unchanged selection and dispose instance buffers on selection changes. Display-budget or unsupported geometry omissions are reported.

The shared bundle is included in Chromium, Firefox, VS Code, web and Android packages. Browser/phone-viewport checks use a retained synthetic four-layer fixture; they do not establish installed acceptance on every host or manufacturing-grade geometry.

Marketplace publication is deliberately pending at the user's request. Mozilla's existing listing remains restricted; an appeal has been recorded. GitHub download publication is separate from either store's approval. The APK remains development-signed and the AAB unsigned.
