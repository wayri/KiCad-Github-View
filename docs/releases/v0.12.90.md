# KiCad Online 0.12.90 / Android 1.92

- Move Projects/dashboard into the top workspace navigation. Standalone drawing viewers keep the action in their top toolbar. Remove the duplicate side-ribbon action.
- Put Draftsman drawing tools and save/export actions above the document. On narrow screens, Tools and Save & export open downward from the top and dismiss on outside click.
- Add **Ortho** beside the 3D view selector. Choose Top or press Z for an undistorted top-down view. Switching projection preserves target-plane scale and view direction; the popup has an independent orthographic toggle.
- Add **Highlight layer** to the floating PCB layer selector: emphasize the selected layer while keeping other visible layers as dimmed context. **Isolate layer** remains available; mouse-wheel and arrow cycling follow the chosen style. Overview restores the previous visibility.
- Keep 3D pad labels, picking, comment anchors, probe guide links, fitting and antialiasing attached to the active camera.

## Verification and limits

[UI acceptance and screenshots](../QA-TOP-CONTROLS-0.12.90.md) cover the production Draftsman at desktop and phone widths, outside-click dismissal, Top + Ortho and switching back with Sharp antialiasing. Camera tests cover depth independence, target-scale preservation, fit/resize and BGA annotations. Tests use small saved fixtures; this is not new installed-store or physical-device acceptance.

Source gates: 2,412 JavaScript tests passed in the final full gate; 149 Python tests passed with one Windows symbolic-link privilege skip.

The existing layer-colored net mode from 0.12.89 is retained. Altium beta remains separate and excluded. The Android APK is development-signed and non-debuggable; its unsigned AAB is not ready for Google Play upload. GitHub publication and platform review/approval are separate.
