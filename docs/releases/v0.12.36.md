# KiCad Visual Review v0.12.36 / Pocket KiVi Android 1.41

Adds KiCad 8 saved-file viewing and explicit feature compatibility guidance across the shared browser, VS Code and Android viewer.

- Recognized KiCad 8 symbol/footprint geometry, hidden fields and PCB tstamp identities remain available along with selection, comments, comparisons and sheet navigation.
- A compact Features control lists supported and blocked capabilities. Accessing a newer-format feature from a KiCad 8 drawing explains the restriction and recommends the latest stable KiCad, saving an upgraded copy. Viewer limitations are distinguished explicitly: upgrading alone does not enable unimplemented features.
- Includes the latest frozen mobile source: temporary/large-project download handling, GitHub notifications, all-sheet overview and compact presentation improvements. Existing source and native-runtime limits remain documented.

Verification: 70 Python and 921 JavaScript release tests passed. Android debug build, lint, unsigned bundle and instrumentation build passed. Android 1.41 was installed on the connected phone with data retained; 84 isolated native persistence checks passed, alongside 32 production ZIP-reader checks and 14 notification-link checks. KiCad 8 verification uses synthetic headers and unmodified older saved-format fixtures from the official 8.0.0 QA corpus; native KiCad 8 pixel certification is not claimed. The popup was inspected in the actual shared viewer with mocked transport at desktop and phone widths in light and dark themes.

Development distribution: Android APK is development-signed, the AAB is unsigned, Firefox and Safari packages require development installation. Store publication is not implied.
