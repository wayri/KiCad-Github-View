# KiCad Visual Review v0.12.33 / Pocket KiVi Android 1.31

This release adds a phone/tablet workflow to Pocket KiVi and saved analysis viewing to the shared browser project viewer.

- One schematic canvas shows all loaded sheets with page names. Selecting a connected net retains matching sheets and draws logical intersheet airwires.
- Compact Android controls separate library/accounts from active-project actions. Properties and comments open as draggable previews; comment editing adapts to keyboard space. Comments emphasise the message and thread with smaller metadata and distinct issue/discussion markers.
- The Android home screen lists recently opened projects in opening order, with Online, Online · available offline, or Offline only indicators. Local files are remembered without silently copying them; Save offline enables one-tap reopening.
- Large public GitHub projects offer Download/Cancel, stream a commit-pinned offline copy into app storage, and appear in recent/starred projects for one-tap reopening. Public files support up to 256 MiB; private Contents API files support 100 MiB; projects support 1 GiB. Git LFS and private files above the API limit remain unsupported by automatic downloads. GitLab/local import limits are unchanged.
- The mobile Layout toolbar has a direct 2D/3D switch. Part, net and group highlights transfer between 2D, 3D and schematic/layout cross-selection. Selection persists across mode changes. Portrait fitting and orbit/pinch selection handling are improved; the shared properties panel replaces duplicate 3D inspection UI.
- Saved WayriCAD QuickPI, QuickSI, QuickTherm, mechanical, sweep and other JSON/CSV reports have graphs, fields, meshes and searchable metadata. KiCad workbooks show setup; exported CSV or ASCII SPICE RAW supplies waveform data. No solvers run. VS Code graphical analysis is currently unsupported by its nested-frame CSP.

Verification: JavaScript and Python release gates, Android compilation/lint, binary asset/signature/version audits and local phone/tablet viewer fixtures. APK installation and launch were verified on a Samsung Galaxy A36 (version 1.31, code 34). Physical-device feature tests and live Marble/private repository download acceptance have not been performed. Local fixtures do not establish installed browser acceptance.

The 3D engine renders saved front/back copper, vias, bounded footprint stand-ins and supported local/repository models. Inner-layer copper is not rendered. Highlights are bounded at 2,000 visible objects with a count notice for larger selections. Cross-sheet connectivity retains existing hidden-power-pin, bus and reused-instance limitations.

Android APK uses development signing; AAB is unsigned. Firefox is an unsigned development extension. Safari requires macOS conversion/signing. VS Code Marketplace and other store publication are separate. All target source code is in the tagged repository; Android also includes a dedicated source archive.
