# KiCad Visual Review 0.12.45 / Pocket KiView Android 1.58

This prerelease fixes the overlapping part/net selection helper in Android and
the browser extension. Android uses versionCode 61.

- The helper remains a compact popup beside the selected point, with no Android
  bottom-sheet conversion or rounded drag handle.
- It opens above or to the left when the viewport edge leaves insufficient space,
  and stays scrollable within the available drawing viewport.
- Focusing a choice does not scroll the drawing. Choosing a part or net retains
  existing cross-highlighting and dismissal behavior.
- Browser geometry uses explicit DOMRect dimensions; regression checks cover
  non-enumerable browser rectangle properties, edge placement and keyboard-sized
  viewports.

The picker was visually checked in phone-size and desktop browser fixtures using
the production picker construction and Android styles. This is not a claim of
physical-device selection acceptance. Shared tests, Android build/lint and exact
packaged-asset audits are release gates.

The APK is development-signed. The AAB is unsigned and requires upload signing
before Play submission. Browser-store and native Safari acceptance are separate.
iPhone source and builds are excluded. Source commit, package audits and SHA-256
checksums accompany this release.
