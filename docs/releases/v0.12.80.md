# Pocket KiView 0.12.80

- Fixed schematic/layout/3D component cross-probing when KiCad stores a root-relative PCB association and a root-qualified schematic association. Saved identity now survives properties-panel truncation. Ambiguous and foreign-sheet matches remain rejected.
- Schematic probes have independent sheet selection and previous/next highlighted occurrence navigation, including repeated sheet instances, without navigating the main drawing.
- Added main and popup view flip and 90-degree rotation. Main shortcuts: D datasheet, C comment, P probe, F flip, R clockwise, Shift+R counterclockwise; drawing theme moved to T. Shortcuts leave editable fields alone.
- Orientation is retained in linked and portable review views. Popup cameras remain independent.

Android app version: 1.80 (83). Browser and VS Code version: 0.12.80.

Validation and browser acceptance evidence are recorded with the release artifacts. Saved source files are not modified by these view operations.

- Improved office-managed browser diagnostics: required website/raw viewing is separate from optional API/account access, explicit administrator restrictions have clear categories, and local-file help stays available without bypassing policy.
- Component guide lines attach to saved pads/body geometry instead of distant field text.

Checks:2,198 JavaScript tests passed;149 Python tests completed with one Windows symlink-permission skip. Android build/lint passed.
