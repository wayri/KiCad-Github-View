# v0.12.25 — Toolbar search

Schematic and PCB viewers now have a compact search box in the navigation toolbar. Search references, values, saved properties, nets and loaded sheet paths, then click a result or use arrow keys and Enter to jump to it. Press `/` to focus search and Escape to close results. Search does not force the explorer open.

Loaded drawings are searched immediately with debounced input. **Search entire project** explicitly loads the bounded repository/workspace search index at the current source revision, including results in other drawings. Existing field and pattern queries remain available.

Validation: shared workspace regression tests cover part/net jumps, sheet navigation, keyboard controls and absence of automatic project fetches. Browser preview checks use production viewer code with fixture transport; installed private-repository authentication and store acceptance are not claimed. Firefox remains unsigned; Safari requires macOS conversion and signing.
