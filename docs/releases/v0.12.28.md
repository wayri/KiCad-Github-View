# v0.12.28 — Floating PCB layer selector

The 2D PCB viewport now has a compact floating layer selector, available without opening the project explorer. Buttons follow the saved board copper layers and their renderer colors, including inner layers. A copper button isolates that layer while retaining board outline context. All shows all saved layers; Overview restores visibility from before the first focus or preset. Explorer controls and keyboard layer changes update the selected button. The overlay scrolls on narrow views and hides in 3D and schematic views, without consuming a permanent toolbar row.

Validation: regression coverage checks saved layer enumeration, isolation, all layers, visibility restoration, and 3D/schematic behavior. Full release tests and package audits are required. Browser visual checks use production viewer code with fixture transport; installed browser/store acceptance is not implied. Firefox is unsigned; Safari requires macOS conversion and signing.
