# Pocket KiView 0.12.60 / Android 1.62

Phone UI refinement, building on the cancellable loading and KiCad Default
palette changes in 0.12.59.

- Compact folder/file rows replace file cards. Folder indentation, disclosure
  arrows, file icons and single-line names preserve a clear hierarchy.
- Search includes matching files and their parent folders. Long names truncate
  visually while retaining their complete accessible name and path.
- Project tools use aligned navigation rows, separate from primary actions.
- Consistent touch targets, icon slots, form spacing, readable placeholders and
  page gutters; native safe-area handling remains in place.
- Shared repository browsing uses the same refined rows across clients.

Validation details are in docs/VALIDATION-2026-10-26.md. Browser phone/tablet
previews use synthetic project data; no new physical-phone acceptance is claimed.
Store publication is separate from local package preparation. iPhone/iPad work
remains excluded.
