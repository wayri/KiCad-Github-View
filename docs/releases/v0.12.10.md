## Comments and paired review

Comment actions now reveal the editor even in Focus view or short split panes. The composer expands when needed; close it to maximize the drawing again. Explicitly expanded panels temporarily use more drawing space. Drafts survive panel changes.

Split schematic/PCB views visibly highlight corresponding saved parts. Net cross-highlighting resolves unambiguous saved hierarchical sheet names in both directions and opens the matching subsheet. Selections made while the companion loads are replayed after it is ready. Reused sheets, ambiguous references and unproven hierarchy links require explicit selection; this does not implement a full KiCad hierarchical netlist or bus resolver.

**Mention people** lists GitHub repository contributors/assignees or GitLab project members. An explicit other-user search is also available. Select a result to insert @username, or type one manually. Lookup requires account access, uses bounded background requests, and rejects results after account changes. No notification is sent until publication. Roles are suggestions, not access guarantees.

GitLab publication uploads captured PNGs to the verified numeric project and embeds validated image URLs in issues and issue discussions. Private/internal projects must require authentication to view media files before image publication. Confirmed uploads are reused; uncertain outcomes block automatic retry. Remote private image previews may additionally require GitLab website sign-in. Removing a local note does not delete remote uploads. Live publication remains unverified.

## Large drawings and GitLab merge requests

Large drawings use a bounded spatial index for drawing and picking. Automatic WebGL gesture acceleration reprojects a bounded Canvas snapshot during pan/zoom and settles back to source rendering. It is not a GPU vector renderer; unsupported contexts fall back to Canvas. No frame-rate guarantee is claimed.

GitLab current merge-request Changes pages can preview saved drawings at pinned target/source revisions, including forks. Discovery must be complete and bounded. Historical change versions and merge-request comment publication are not implemented.
