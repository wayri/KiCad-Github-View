# Pocket KiView 0.12.57 / Android 1.59

This preview packages the current Chromium extension, VS Code extension and Android app. iPhone/iPad source and artifacts are excluded.

## Changes

- BoM field tables and grouping by value, footprint, rate or custom fields; per-part and filtered/whole-source resets with scope warnings and explicit acknowledgement.
- Compact local-workspace headers, adjustable parallel panes, drawing toolbar icons and phone layout improvements.
- Shared testpoint search/navigation, board settings tables, hierarchy links and preserved drawing state when returning from engineering tools.
- Expanded interactive calculators and shared engineering viewers; availability differs by host.
- Copper net-name overlays, provider-access improvements, visual Git conflict review in VS Code and portable review workflows.
- Updated support address: support@sigharmonic.com.
- Illustrated README/user guide, WayriCAD saved-result compatibility guidance, corrected garbled text and direct release downloads.

## Packages and installation

- Chromium ZIP 0.12.57: extract and load unpacked in a supported desktop browser.
- VS Code VSIX 0.12.57: Extensions: Install from VSIX. Marketplace publication is a separate channel.
- Android APK 1.59/code62: development-signed; install manually on Android 8+. Updates require a compatible signing identity. Export data before any signing-channel migration.
- The unsigned Android AAB is a build artifact, not a directly installable app or Play-ready upload.
- Firefox and Safari packages retain their documented development/signing limitations.

See INSTALL.md, USER-GUIDE.md, release-manifest.json and SHA256SUMS.txt supplied with or linked from the release. The license is source-available; third-party terms continue to apply. Existing releases keep their original terms.

## Validation scope

Automated checks and archive/source audits are recorded in the release manifest and build evidence. This release does not claim a new physical-device test, native Safari acceptance, Play review or numerical solver qualification. Recognized KiCad constructs, saved results, proxies and inferred connectivity retain their documented limitations.
