# KiCad Visual Review 0.12.42 / Pocket KiView Android 1.54

This prerelease adds offline project review, board analytics and review transfer,
and simplifies Android's drawing tools. Android uses versionCode 57 and package
`dev.kicadvizdiff.android`.

- Android drawing tools present six primary actions and collapsed Display,
  Highlighting, Navigation & properties and More tools sections. Existing
  controls retain their state and handlers; the duplicate BoM shortcut is removed.
- Shared tool icons include distinct ERC/DRC icons and calculators. Findings and
  saved-report markers have independent show/hide controls. No live ERC/DRC is run.
- Board analytics report saved geometry, trace lengths, zone areas, placement
  evidence and routing candidates, retaining their source and approximation limits.
- Portable review handoff transfers verified review state between app and
  extension. Import does not publish comments or modify CAD sources.
- The local browser workspace opens saved schematics and PCB projects without
  internet or a KiCad installation; folder/file drop preserves relative paths.
  A native KiCad launcher opens the same browser review interface.
- Approved GitHub and GitLab project tabs can supply signed-in session reads for
  private repository review. Reads remain bounded and confined to the approved
  host/project; remote publication still requires the connected-account flow.
- Engineering tool entry points expose PDF, Gerber, BoM and offline calculators.

The downloadable Android APK uses development signing. The AAB is unsigned and
is not a Play Store upload candidate. Native Safari, physical camera/AR and
installed-extension acceptance remain separate checks. iPhone source and builds
are excluded from this release.

The release pipeline runs Python and JavaScript acceptance checks, Android
debug/lint/release builds, and source-to-package audits. The accompanying manifest
and checksums identify the exact release source and assets; see build evidence for
actual outcomes. Phone installation is reported separately from publication.
