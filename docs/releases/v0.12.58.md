# Pocket KiView 0.12.58 / Android 1.60

This preview updates Android, Chromium and VS Code from the same source revision.
iPhone/iPad work and artifacts remain excluded.

## Changes

- Shared repository file tree, branch selection and colour-coded commit graph for
  authenticated GitHub/GitLab projects; real parent relationships, commit messages,
  author/date details, revision-pinned pagination and lazy folder browsing.
- VS Code working-file status colours and Git history, with fresh HEAD on refresh,
  pinned older pages and workspace-trust checks. Historical committed file trees
  remain unavailable through the public VS Code Git API.
- Cleaner 3D selection: component bounds replace overlapping triangle wireframes;
  instance geometry sizes, depth visibility and linked/embedded-model refresh fixed.
- Android UI refinement: full-window drawing area with cutout-aware controls,
  hideable right tool rail, explicit context-menu properties, dedicated pages,
  improved menu spacing and authorization cancellation/scope handling.
- Compact desktop headers, focus/restore view, collapsed BoM advanced controls and
  drawing-first visual conflict review.
- Testpoint quick highlighting, filters, search and readable net names. GitHub issue
  state and local review state are displayed separately.
- Faster parsing, cached net/selection geometry and bounded concurrent imports.

## Validation

1,318 JavaScript checks passed. Python completion suites: 58 passed, one skipped.
Native emulator acceptance: 1,498 library/auth/transport checks, including 210
repository metadata checks, plus 14 UI checks. Android build and lint passed.
See docs/VALIDATION-2026-10-26.md for scope, evidence and limitations. The release
build runs additional source/package audits; no new physical-phone acceptance is
claimed. Firefox and Safari packages retain their development/signing limits.

## Install

- Chromium ZIP 0.12.58: extract and load unpacked, or reload an existing local copy.
- VS Code VSIX 0.12.58: Install from VSIX; Marketplace is a separate channel.
- Android APK 1.60/code63: development-signed preview, Android 8+. Preserve data if
  Android reports a signing mismatch; do not uninstall just to bypass it.
- Android AAB is unsigned and is not a directly installable or Play-ready package.
