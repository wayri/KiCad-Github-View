# Pocket KiView 0.12.84 / Android 1.87 — documentation and distribution preview

Chrome/Chromium, Firefox and VS Code packages use **0.12.84**. Android uses
**1.87**, version code **90**.

This is a documentation and packaging refresh of 0.12.83. It does not add a new
design parser, solver or viewer feature. The shared engineering functionality
and its known limits remain as described in [0.12.83](v0.12.83.md).

## Included documentation

- The illustrated capability collection contains 123 screenshots: 67 current
  0.12.83 captures and 56 explicitly historical images, with public-board and
  synthetic analysis evidence distinguished.
- README and user-guide links point to the searchable gallery and the capability
  coverage/gaps index. Current source, store approval and physical-device
  acceptance remain separate claims.
- The guides archive now includes the versioned searchable HTML gallery and its
  collection manifest, alongside images and Markdown. Packaging tests check
  inclusion and reject unrelated HTML/JSON filenames from this allowlist.

## Altium remains separate

The experimental local Altium SchDoc/PcbDoc viewer is **not included** in Chrome,
Firefox, VSIX, Android or other release archives. It remains a separate local
test installation. This release does not advertise Altium compatibility.

## Distribution and verification limits

GitHub release packages do not imply Chrome Store, Marketplace or Mozilla
approval. The Firefox ZIP is unsigned and supports temporary developer
installation; a signed Mozilla XPI requires a separate submission and review.
The Android APK is a non-debuggable development-signed preview; the AAB is
unsigned and not Play-ready. No new device acceptance is implied by rebuilding.

The exact source commit, asset hashes and package/source audit are recorded in
the release manifest. Final automated gate results are recorded with the
published distribution status. No private organization sources or screenshots
are included.
