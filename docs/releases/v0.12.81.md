## Distribution and limits

Firefox ZIP is unsigned and requires temporary developer installation; this GitHub release does not reinstate the disabled Mozilla listing. Android APK is development-signed and non-debuggable; the AAB is unsigned and not Play-ready. VSIX supports manual installation. Store publication and phone installation are separate.

Public Olimex ESP32-PoE M2 and matched cross-probe fixtures provided browser evidence. Copper visual checks disclosed stand-ins. These checks do not establish all-board or all-GPU compatibility. See [client-side repository loading](../CLIENT-SIDE-REPOSITORY-LOADING.md) and [user guide](../USER-GUIDE.md).
