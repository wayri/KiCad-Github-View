# KiCad Visual Review v0.11.0 — preview release

Interactive KiCad schematic and PCB review directly in GitHub through the browser extension, plus read-only VS Code custom editors. All design rendering happens in the browser; an optional native report tool and separately deployed GitHub App are also included in the source repository.

## Included

- Owned schematic/PCB renderers, page/title-block display, light/dark UI and board themes, hierarchy navigation, saved part properties and net highlighting.
- Linked visual revision comparisons, branch/file-commit picker, saved-object changes, split schematic/PCB review and cross highlighting.
- Multi-component/net/net-class highlights, bounded regex/wildcard project search and imported ERC/DRC report navigation.
- Snap-aware ruler, layer focus and board extent measurements.
- Assembly variants, BOM / Stats, DNP highlighting/filtering and CSV export.
- Saved project settings, constraints, physical stackup and file navigation; native browser Gerber/drill viewer.
- Object/point/area review comments, severity/tags/state/mentions, Git-trackable sidecar and explicit GitHub issue/discussion publication.
- Repository-linked WRL/VRML and self-contained GLB models in SPIKE 3D.
- Opt-in isolated self-contained HTML/iBOM preview; static HTML fallback in VS Code.

## Installation

Download the browser ZIP or VSIX and follow `INSTALL.md`. The `app-web` and `github-app` ZIPs are optional deployment payloads. GitHub Releases does not install the extension automatically and does not publish it to extension stores or GitHub Marketplace.

## Verification and limits

The release workflow runs the JavaScript suite, Python suite and package/source audits on the tagged checkout, then generates SHA-256 checksums. Native CLI tests skip on runners without KiCad. Local development evidence for the preceding build included 351 JavaScript tests and three packaging checks; the workflow includes additional release checks. See Actions logs for the actual test results for this tag.

Browser UI checks used real renderers with mocked GitHub transport. Live installed Chrome/GitHub behavior, GitHub OAuth/comment publication and native editor visual acceptance are not yet established by those fixtures. Isolated HTML rendered locally; its interaction could not be verified end-to-end with the available browser automation.

KiCad 9/10 recognized constructs are covered by header/geometry tests; native references use KiCad 10. KiCad 11 remains a forward preview with warnings, not verified support for unreleased features. Rendering is not pixel-identical to KiCad. Repeated sheet instances, full cross-sheet connectivity and effective constraint evaluation remain incomplete.

Zone areas are sums of saved straight-edge polygons, with overlap counted repeatedly and separate hole contours not subtracted. Track-length analytics exclude arcs. They are not an exact copper union or material/mass calculation. ERC/DRC markers display imported reports rather than running native rule checks.

Gerber macros and curved regions are omitted with diagnostics; transforms, step-repeat and drill slots are rejected. STEP 3D models remain unsupported. External HTML assets are blocked; HTML selections do not synchronize with the KiCad viewer. No routing, component movement or design editing is enabled.

OAuth needs an owner-registered client ID. Marketplace/store publication and hosting remain separate. Owner code is not currently open-source licensed; see the repository's `LICENSING.md` and `THIRD-PARTY-NOTICES.md`.
