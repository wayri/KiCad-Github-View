# KiCad Online 0.12.85 / Android 1.88

Fresh public branding across browser, VS Code, Android, web and native companion
interfaces. Formerly Pocket KiView / KiCad Visual Review. The repository is now
[wayri/KiCad-Online](https://github.com/wayri/KiCad-Online). This independent project
is not affiliated with or endorsed by KiCad.

- Updated launchers, titles, About, notifications, guides and store copy.
- Retained installed IDs, authentication callbacks, review formats, compatible
  asset filenames and the existing license title. No new permissions.
- Firefox Android: desktop pop-out actions open supported internal viewer tabs
  when the windows API is absent. Permission failures are not retried or bypassed.
  Desktop 140+ and Android 142+ are declared; physical mobile acceptance is pending.
- Local/offline use remains available. The Altium beta is separate and excluded.

This is a branding/mobile-compatibility update, not a new solver or rendering
accuracy claim. It includes the documented 0.12.83 engineering features and
0.12.84 guides. Fast PI remains experimental single-net fixed-temperature DC
screening. Native ERC/DRC/simulation engines are not executed. Organization and
browser policies still apply.

Build evidence is recorded in the release manifest; store upload and approval
are separate. Android preview is development-signed and non-debuggable; its
unsigned AAB is not Play upload-ready.
