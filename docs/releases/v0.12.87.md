# KiCad Online 0.12.87 / Android 1.89

- Add compact comment actions beside property fields and drawing-linked BoM cells, including grouped reference lists.
- Retain saved part identity, revision, location, field name and reviewed value in notes, exports and GitHub/GitLab annotation Markdown. Values remain read-only.
- Show all grouped references in review labels instead of only the first part.
- Reuse the existing explicit local-save and provider-posting flows; no new permissions.

Browser acceptance used the production shared viewer with a retained public OLIMEX ESP32-PoE M2 board and a small grouped fixture. Property/BoM drafts, saving, editing, reload persistence, markers and Locate were exercised. Provider round trips are covered by deterministic tests; no new live provider post or installed-browser/device acceptance is implied.

The local QA server now avoids reverse-DNS startup delays. Altium beta remains separate. Standalone imported BoM report tables are outside this field-comment workflow. Group reviews support up to 100 references; ungroup larger selections first.

All four platform packages are prepared together. Store uploads are scheduled for 6 November 2026; submission and approval are separate. Android APK uses the existing development signer and is non-debuggable. The unsigned AAB is not a Play upload artifact.
