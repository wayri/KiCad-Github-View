# v0.12.8 - Focused drawing space and secure STEP preview

Project drawing previews open in focused mode, hiding the outer project tree and setup headers. Show project controls restores them without reloading the drawing or losing comment drafts. A local 1707 x 960 check measured 80.3% unobscured drawing area with Comments open. That measurement uses the actual renderer with mocked transport; it is not a guarantee for every browser size or installed GitHub page.

Repository-linked STEP/STP models now tessellate in an interruptible Open CASCADE WebAssembly worker and use the saved model/footprint transforms. The pinned-source importer is rebuilt with Emscripten 3.1.69 and dynamic JavaScript generation disabled, preserving the extension security policy. Conversion passes a no-dynamic-code regression and the inherited-CSP browser blob-worker check. The linked cube fixture renders real geometry, with 1/1 model coverage and no console errors. Limits are 8 MiB per model, 30 seconds per conversion, and 500,000 vertices/triangles. Face-level colors and strict temporary tessellation-memory bounds are not established. Missing assets retain labelled proxies; Marble's absent CERN model library still needs repository mappings and assets.

The release includes the corresponding-source ZIP, pinned source archives, rebuild recipe, dependency licenses and recorded binary hashes. STEP remains a development preview. Bit-for-bit rebuild reproducibility, installed-browser/private-host STEP workflows, and native VS Code webview 3D visual acceptance are not established.

Windows VS Code Open and Split commands now handle drive prefixes correctly. Workspace boundaries accept equivalent drive-letter casing while preserving provider, authority, query, fragment and directory checks. An actual isolated native host smoke opens schematic and PCB editors, loads two sheets, saves/reopens a review note, and reads the linked STEP asset without altering drawing sources.

Local gates passed: 542 JavaScript tests and 59 Python tests with one skip. The complete browser/VSIX/source-companion package build passes. The worker bundle is checked against its sources and tested across LF/CRLF checkouts; hosted Linux CI passed on the preceding implementation commit. Firefox remains an unsigned development ZIP; Safari requires a Mac conversion, signing and runtime verification. This is a prerelease, not store certification or full installed-platform acceptance.
