# KiCad Visual Review v0.12.32

This preview publishes the latest shared viewer, VS Code conflict review and Android phone/tablet app (1.26).

- Saved schematic and PCB field visibility now respects direct and effect-level hide flags, including explicit hide=no. Hidden datasheets and custom properties stay off the drawing.
- VS Code visual conflict review includes searchable properties on both sides, highlighted value/visibility differences, and the counterpart value for comparison.
- Added, removed and absent parts have persistent status labels. Whole-part changes do not repeat per-field removal notices. Saved UUIDs identify parts; reference fallback is limited to missing identities.
- Conflict drawings show references by default, with Show field values restoring saved visible labels. Overlapping selectable parts open a chooser; source positions and visibility are unchanged.
- Conflict review overlays changed references/values as current → incoming labels. Selected PCB parts show from/to movement arrows. Git commit dates identify the newer commit only when resolvable; unknown provenance is not guessed.
- Browser packages include the latest shared renderer fixes. The native conflict resolver is available in VS Code, not in Android/browser source viewing.

Verification: renderer/property/VS Code host regression tests, browser comparison fixtures, package inventories and hashes, Android compilation and lint. Local fixtures do not establish live GitHub or installed browser acceptance.

The visual resolver accepts a whole side across all conflicts, validates syntax/root before saving, and separates saving from explicit Git staging. Native ERC/DRC and project-wide/per-conflict visual assembly are not implemented. Unsaved or detected external edits stop saving; provider writes cannot guarantee atomic compare-and-swap against other processes.

Android APK uses development signing; AAB is unsigned. Firefox requires signing for normal distribution; Safari needs macOS conversion/signing. Store publication is separate. Source code for all targets is included in the tagged repository; Android also has a dedicated source archive.
