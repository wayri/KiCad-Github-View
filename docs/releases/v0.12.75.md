# Pocket KiVi 0.12.75 / Android 1.75

Improves 3D model recovery for projects authored on different computers:

- Resolves legacy KISYS3DMOD and parenthesized KiCad library variables against
  models actually included in the project.
- Corrects uniquely matching model path casing, helping Windows-authored boards
  whose assets use different capitalization on GitHub or other case-sensitive hosts.
- Finds a unique same-path/stem STEP or VRML alternative when the referenced
  representation is absent. The renderer uses the selected format's unit scale.
- Reports missing project library models with actionable guidance. Ambiguous
  matches are rejected; no arbitrary URL fetching or basename guessing is added.

Models installed only in a desktop KiCad library are not bundled automatically.
Include the model files with the project for browser/offline viewing. Existing
asset size, decoded-geometry and external-resource safeguards remain in force.
These fixes do not establish that every STEP/VRML model can be decoded.

Retains 0.12.74's detachable schematic/layout/3D browser windows, independent
cameras and project/revision-scoped cross-selection toggle. Native Android and
VS Code Webviews retain split views; native floating windows remain unsupported.
Experimental Fast PI limitations remain in docs/FAST-PI.md.

Android 1.75/version code 78 uses the existing development signing channel.
The unsigned AAB is not ready for Play upload. Store approval is separate from
GitHub publication.
