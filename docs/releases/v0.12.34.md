# KiCad Visual Review v0.12.34 / Pocket KiVi Android 1.32

This release refines mobile selection and navigation, fixes provider logo sizing, and prepares the Android project for Google Play submission.

- Properties list connected nets with direct highlight buttons and pin/pad counts. Matching-sheet links follow the selected net.
- Android exposes Smart, Part and Net selection directly in the drawing toolbar. Split view and comparison controls sit alongside Project, Schematic and Layout navigation.
- GitHub and GitLab logos use consistent bounded sizes on phones and tablets.
- Android includes an offline privacy policy and an opt-in upload-key signing configuration. The explicit bundlePlayRelease task refuses to build without complete signing credentials. Local signing files are excluded from source archives.
- Play Store listing copy, a privacy policy, a Data Safety worksheet and submission instructions are included in the guides and tagged source. Console account verification, production signing, store screenshots and final policy declarations remain operator steps. No Play Store submission is claimed.

The shared viewer retains v0.12.33 features and documented limitations. The Android APK is development-signed; the public AAB is unsigned and cannot be uploaded to Play until rebuilt with an upload key. Firefox and Safari remain development distributions. See the release manifest for build/test and source provenance.

Verification: 70 Python tests and 864 JavaScript tests passed; Android debug compilation, lint and instrumentation compilation passed. Missing upload-key configuration was rejected. The signed-bundle task was built with a disposable test key and its JAR signature verified, then the public unsigned bundle was rebuilt. No production signing identity was created and no Play Console upload was performed. Release audits verify source, staged viewer assets, versions, signatures and checksums.
