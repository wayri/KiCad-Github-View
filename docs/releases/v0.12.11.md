# KiCad Visual Review v0.12.11

## Comment filters and sorting

In **Comments → View comments**, **Filter and sort comments** now opens by default with a compact two-column layout. Filter by Open, Closed, Skipped, an exact review state, severity, read status and search text. Closed groups Resolved and Won’t fix review notes; it does not refer to the remote Issue or Discussion state.

Sorting supports severity highest/lowest first, creation date newest/oldest first, and update date newest/oldest first. Reset filters restores all notes in severity order. The same filters apply to drawing annotation markers and unread navigation. Filtering and sorting never change saved notes or publish anything.
