# Pocket KiVi 0.12.78 / Android 1.78

- Refined 3D copper geometry: saved-width rounded tracks, bounded adaptive arcs/pads/drills, opaque ordinary saved fills, corrected outer-copper/substrate elevations including asymmetric stackups, and drill-bore walls without invented plating thickness.
- Added Sharp edge antialiasing, clearer rendering diagnostics, antialiased bounded-resolution 3D probes and finer bounded STEP conversion. Original model normals and source geometry remain authoritative.
- Interactive miniature schematic/layout/3D probe windows support independent pan/zoom, movable headers, 2D rotation, cross-probing and sibling windows. Up to four probes are supported, with at most two 3D probes alongside the main 3D context. Curved visual links can be hidden.
- Removed oversized 2D selection rectangles while retaining selected source-geometry highlights.
- Draftsman exposes final PDF downloads and saves PDF, SVG and editable source together to a new repository branch. Download links remain available while the workspace is open. Repository writes require an authorized account and explicit user action.
- Improved dimension snapping, saved-page visibility and bounded canvas drawing caches/batching. Added Gerber inventory/analysis details and bounded automatic ERC/DRC report discovery.
- Improved local import handling, project-file hierarchy support and legacy file handling within documented preview limits.
- Repaired the tools spanner, separated Maximize/Restore from Fit icons, resolved missing Project glyphs, and aligned compact toolbar controls across light/dark themes.

## Verification and limits

Browser acceptance used retained real public Olimex ESP32-PoE source and saved inspection/report fixtures. Automated geometry, source identity, lifecycle, export, transport and rendering checks accompany these changes. Package audit results and source commit are recorded in release-manifest.json.

An intermittent enhanced-graphics fallback remains: Balanced rendering stays available when the optional postprocessing pipeline fails. Antialiasing does not restore detail absent from original polygonized outlines or model meshes. Model availability depends on included assets; no claim is made that every repository model loads. No measured frame-rate improvement is claimed. Installed store-extension, VS Code GPU and Android hardware acceptance are separate from local browser verification; physical-phone installation is not part of this release build.

Android 1.78 / version code 81 uses the existing development signing channel with debugging disabled. The unsigned AAB is not ready for Google Play upload until an upload signing key is configured. Store submissions and approvals are separate from this GitHub release.
