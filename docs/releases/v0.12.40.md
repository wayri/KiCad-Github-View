# KiCad Visual Review v0.12.40 / Pocket KiView Android 1.52

This prerelease strengthens the everyday assembly and debugging workflows shared by the Android app and browser extension. Android uses versionCode 55 and package `dev.kicadvizdiff.android`.

- BoM/assembly and testpoint inspection are direct drawing-toolbar actions. Photo inspection remains available in an optional section of the assembly panel.
- Next unfinished part navigates through fitted, included, unverified components within the current filters. Navigation does not advance checklist status. Whole-source verified counts remain visible alongside filtered progress, and DNP/excluded components no longer enter quick assembly progress actions.
- Testpoint searches combine reference, net, pad, source file and other supported fields, with quoted phrases. Connectivity, source and detection filters distinguish resolved nets, unknown connections and inferred testpoints. Expandable same-net pads/pins navigate to their exact saved source-file component and pad position; CSV export contains all matching rows.
- Existing schematic/PCB rendering, measurements, DNP/DNI overlays, variants, revision comparisons, local review notes, PDF/Gerber viewing, supported saved analysis results, 3D models and optional photo inspection remain available. The tools inspect saved designs and do not run native KiCad checks or simulation solvers.

Distribution packages include a development-signed Android APK and an unsigned release AAB. The separately prepared upload-signed Play bundle is a deployment candidate; Google Play upload and physical-device acceptance are separate from GitHub prerelease publication.

Full Python/native-KiCad and JavaScript release gates are required before publication. Android debug/lint/release and upload-signed candidate builds passed. Browser checks verified the retained bench fixture at desktop and 389 CSS-pixel phone widths, including same-net pad navigation, queue resume and responsive cards. Package manifests and checksums bind the downloadable assets to their source snapshot. Local browser fixtures do not imply installed-extension acceptance on GitHub or physical camera validation.
