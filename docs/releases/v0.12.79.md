# Pocket KiView 0.12.79

- Improved icon-first GitHub project discovery, nested branch/folder handling and shared immutable source caching. Duplicate website inventory entries are normalized, and raw file reads reject HTML responses.
- Restored legacy schematic sheet navigation, Home/Up and saved root-cache library sharing within the documented restricted legacy preview.
- Added independent pin/pad-number and net-name controls, including saved alphanumeric BGA pad numbers. Bounded annotations are available in main and miniature 3D views.
- Miniature 3D views can inspect selected saved copper across internal layers and explicit via spans, with independent selection, fitting and picking through translucent context. Geometry and annotation limits report omissions.
- Fixed static VRML Switch selection and DEF/USE identifier handling for the retained public LED model. External resources, dynamic constructs, cyclic/excessive alias expansion and unsupported nondefault transforms are rejected explicitly.
- Improved probe positioning, connected-object inspection and 3D focus behavior while preserving independent cameras and saved source identity.
- Improved comment-send recovery after an accepted provider write, readback handling, foreground synchronization/backoff, and retained point/area/sheet metadata. GitHub discussion sends use the selected discussion category and explicit send workflow.
- Added native-style property tables for saved design details. Fast PI batches visual overlays, and Draftsman reduces repeated snapping/export work while retaining bounded source geometry.
- Added readable VERSION.txt files inside distribution archives and a shared About panel showing the packaged version and platform.

## Verification and limits

This preparation targets Chrome/Chromium and VS Code only. Automated source, geometry, transport, selection, lifecycle and packaging checks are recorded with the artifacts. Retained public Olimex, Marble and VNA sources inform acceptance; that evidence does not establish complete KiCad/VRML support or manufacturing/electrical correctness.

These are untagged artifacts built from a dirty working tree. Package evidence records the base commit and checksums; the base commit alone does not reproduce uncommitted changes. No Android app version is changed or Android binary built by this preparation. Store submission, store approval and installed-browser/VS Code GPU acceptance are separate checks. Existing model availability, bounded geometry/annotation omissions and optional enhanced-rendering fallback limits remain applicable.
