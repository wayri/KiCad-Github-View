# Pocket KiVi browser 0.12.72 — icon-first viewing

Chrome/Chromium and Firefox keep normal GitHub/GitLab repository, drawing and pull/merge-request pages untouched. They no longer automatically insert a viewer, hide source code or start preview/discovery reads on those pages. Click the toolbar icon to open the standalone viewer or project chooser from 0.12.71. A single detected project opens directly; multiple projects remain selectable, and empty, partial and denied listings have distinct feedback.

The small content bridge remains available for explicit toolbar context and authorized signed-in repository reads. Legacy inline preview handling is gated behind an explicit extension request for the current URL; ordinary navigation does not activate it. Existing draft handoff remains user-directed. No new permissions are requested. Refresh existing repository tabs after updating to remove controls from an older build.

This includes the earlier Draftsman templates/snapping and review features. Android remains 1.72 in v0.12.70; there is no new Android binary for this browser-only change. Store publication is separate from GitHub downloads. Mozilla's existing listing remains disabled, so its Firefox ZIP remains an unsigned development package.

Validation covers ordinary GitHub/GitLab file and PR browsing without automatic mounts/reads, explicit legacy rendering, standalone icon routing and read-only discovery boundaries. Full JavaScript and affected package tests pass. Installed Firefox and every managed-browser configuration are not implied by these tests.
