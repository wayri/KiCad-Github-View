# KiCad Online 0.12.86

License and presentation update for VS Code Marketplace and Mozilla Add-ons.

- Renamed the custom license to **KiCad Online Source-Available License 1.0** and
  updated product scope naming and licensing references. The permissions,
  restrictions, warranty exclusions and third-party rights are unchanged.
- Firefox packages now include the project `LICENSE.txt` and the unchanged static
  Terms page. Legal pages do not receive the privileged browser API shim.
- Marketplace README adds current saved-comment, comment-composer and dimensioned
  Draftsman screenshots. They use public KiCad demo files in the shared browser
  viewer, with local example notes; they are not live provider conversations or
  installed VS Code captures. Draftsman component bodies in that example are
  fallbacks. Source revisions and limits are documented in the capture guide.
- Direct Chrome, Firefox and VS Code store installation links are in the README.
- Mozilla listing icon and license metadata have been corrected independently
  of package approval. Existing add-on/extension identities are retained.

No new permissions or engineering runtime features. No new rendering, numerical
accuracy or installed-device acceptance claim. The separate Altium beta is
excluded. Android 1.88 is unchanged and is not rebuilt in this release.

Chrome's pending **0.12.85** review is intentionally left running. Any 0.12.86
Chromium GitHub preview does not replace that store submission. Store upload,
validation and approval are separate states; consult the distribution status.
