# Pocket KiView 0.12.62 / Android 1.64

This preview brings the shared viewer, Android app and VS Code extension up to the same reviewed source state.

- Compact headers, menus, settings and properties panels across clients. Phone conversations use a single icon header and a small + / Send composer, with secondary controls revealed on demand.
- Chat-style GitHub Issue/Discussion and GitLab Issue conversations: browse threads, search messages, reply, mention contributors, edit supported own messages, attach drawing context and paste screenshots. Review the destination before sending. Drafts survive conversation switching during the session; saving a local draft does not publish it.
- Optional automatic conversation refresh while visible, with error backoff, reading-position preservation and a new-message indicator. Per-message moderation actions sit behind a compact menu.
- Source-bound context and permission checks, stale-edit protection, duplicate-write protection, native project-scope checks, and safer GitLab credential-refresh sequencing.
- Improved PCB 3D source geometry, footprint stand-ins, rendering quality and selection, plus surface measurements with XYZ deltas and session history. Stand-ins remain approximations; this is not a photorealism or model-fidelity guarantee.
- Five-entry 2D measurement history, grouped drawing tools, improved schematic/PCB colors, saved-report access, and support for recognized KiCad Monkey saved design/netlist reports.
- Startup/access diagnostics, including a visible warning when requests fail or are explicitly blocked. Organization policy is identified only when the host reports it.

## Downloads and installation

Use the browser-named Chromium ZIP for Chrome, Edge, Brave, Opera, Vivaldi and Chromium. Install the VSIX with VS Code's **Extensions: Install from VSIX** command. Android 1.64 (version code 67) is a development-signed APK for manual installation and updates. Preserve project/review data if changing signing channels; do not uninstall to bypass a signature mismatch.

The unsigned Android AAB is a build artifact, not a Play-ready upload. GitHub releases do not update the Chrome Web Store, VS Code Marketplace or Google Play automatically. Firefox remains an unsigned development add-on; Safari requires native conversion/signing and verification.

## Verification and limits

Release packages are audited against the tagged source, with checksums in SHA256SUMS.txt. Verification includes the release test suite, Android build/lint, responsive browser checks and an isolated VS Code host smoke check. Phone, tablet and landscape browser layouts were checked; a physical phone installation is pending because the device is not connected.

Provider posting tests use mocked transports; no live messages were posted during verification. GitHub Issues use linked quoted replies, GitHub Discussions use native replies, and GitLab conversations belong to Issues. Automatic refresh polls rather than providing live presence or typing indicators. Reactions and editing published annotation metadata are unavailable. Timestamp edit checks are optimistic and cannot guarantee atomic conflict detection across clients.

Context remains tied to the saved source revision. Mutable VS Code workspaces may require opening the saved source before locating context. Fork-to-base conversations support text messages but cannot attach context from a different source repository. Native Android chat is restricted to the active project's exact revision and file. Explicitly saved local review notes are limited to 4,000 characters; longer unsaved chat drafts remain in memory until copied or shortened.
