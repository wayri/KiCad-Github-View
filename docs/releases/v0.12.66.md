# Pocket KiView 0.12.66 / Android 1.68 — portable review and precision tools

This preview brings together the latest browser, VS Code and Android changes:

- Separate KiCad/SPICE workbook and waveform views from wayriCAD saved analysis, with supported 2D/3D fields and probing.
- Searchable persistent BoM column choices, custom fields and visible-column CSV export.
- Foldable project folders, filename inventories for other files and paged browsing.
- Browser-generated current-sheet/layout raster PDF and PNG downloads, plus BoM CSV. PDF/image export remains browser-only where a native binary save bridge is absent.
- Edge/corner snapping, object filters and phone magnifier assistance for 2D/3D measurement. Imported meshes retain tessellation precision; stand-in models remain approximate.
- Optional Windows desktop helper for Open in KiCad: Save As a pinned repository archive, validate it, extract a new copy and launch the matching project/editor. Helper setup is explicit; installed-browser/native-launch acceptance is still pending.
- Provider-backed review refresh, pending drafts and engineering work-item UI with source-bound permissions and conflict checks.
- Public GitLab OAuth client configuration and improved Android provider/renderer acceptance checks.
- Adaptive renderer quality and bounded phone framebuffer allocation.

Security gates include scoped provider/native messages, cancellation and policy checks before native launch, bounded ZIP directory validation before allocation, collision/traversal/device-name rejection and no shell execution of repository data. These checks are not security certification.

The APK is a non-debuggable development-signed preview; the AAB is unsigned and is not ready for Play upload. Store submissions and approval are separate from GitHub downloads. Firefox data-consent/readiness changes and verification outcomes are recorded in the accompanying documentation and release manifest.

Screenshots include historical UI and synthetic provider/simulation examples, with their provenance labelled in the README. No solver is run by saved-result viewing, and native KiCad fidelity remains subject to documented parser coverage.

Validation: 1,745 JavaScript tests passed; 129 Python tests passed with one environment-dependent skip. Android assembleDebug, lintDebug, bundleRelease and instrumentation build succeeded. Android 1.68 (71) was installed on the connected phone; 26 publisher OAuth configuration checks passed on-device.
