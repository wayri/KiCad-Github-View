# KiCad Visual Review v0.12.12

## Issues and Discussions

Comments now has separate **Issues** and **Discussions** categories, each retaining **Add comment** and **View comments**. New drafts inherit the selected category and its matching GitHub destination. Issue notes publish to GitHub Issues; Discussion notes publish to GitHub Discussions, with a category required for a new Discussion. Existing thread destinations remain available.

Counts show all annotations in each category before other filters. State, severity, read status, search, sorting, drawing markers and unread navigation work within the selected category. Linked conversations also follow the category. **All** retains older uncategorized notes without modifying their saved records.

Switching categories preserves the text and type of an existing draft. Changing its explicit thread type switches categories. Publication still rejects a mismatched destination. Browsing categories never publishes a comment. GitLab discussions remain replies within GitLab issues; they are not GitHub-style standalone Discussions.
