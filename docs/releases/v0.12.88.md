## Verification and limits

Focused source checks and localhost production-viewer interactions passed before release preparation: guided Fast PI contacts and worker results/overlay, menu dismissal and viewport bounds, and both directions of BoM selection. A bounded sample board was used; this is not installed-store or complex-board/device acceptance. Full source gate: 150 Python tests (149 passed, one Windows environment skip) and 2,403 JavaScript tests (2,402 passed, one skipped). Android offline assemble, lint and bundle passed, with 19 lint warnings and no errors. Package audits are recorded in the release manifest.

Fast PI remains experimental fixed-temperature, single-net 2.5D DC screening. The nominal 58 MS/m conductivity is a visible editable preset, not an inferred saved material. Saved complete stackups are reused; missing physical dimensions and plated-hole thickness remain explicit inputs. Automatic refinement is not a convergence or accuracy study.

Altium beta is excluded. Android APK uses the existing development signer and is non-debuggable; unsigned AAB is not a Google Play upload artifact. Store submission and approval are separate from GitHub release publication.
