# KiCad Visual Review v0.12.38 / Pocket KiView Android 1.50

Pocket KiView expands portable design review with fabrication, assembly and saved analysis tools. The Android version code is 53; the package identity remains `dev.kicadvizdiff.android`.

- Dedicated Gerber viewer and analyzer: aligned layers, independent visibility/color/opacity, pan/zoom, unsnapped distance measurements, drill statistics and configurable geometry screening. Fabrication-only imports and repository navigation are supported. Analysis JSON includes source hashes. Unsupported constructs are disclosed; full manufacturing DFM and routed drill slots are not supported.
- BoM and assembly tools, variant handling, supported iBOM imports and BoM Studio data import. Component cross-selection and saved source provenance connect assembly data to review. Format limits and compatibility evidence are documented in the BoM guides.
- Offline engineering calculators with equations, units and applicability limits. These are selected KiCad-style tools, not the complete native calculator suite.
- Saved WayriCAD results, 2D/3D overlays, probes and plots for supported data. Results are imported evidence; the app does not run the producer's solvers or certify their numerical accuracy.
- Improved repository navigation, quick actions, comment destinations, dedicated settings and KiCad-style themes. Enhanced linked and embedded 3D model handling retains missing-model diagnostics and bounded loading.
- Includes accumulated mobile, foldable/tablet, temporary download, review safety and source-format improvements since the preceding release.

The GitHub distribution remains a prerelease. Its APK uses development signing and its AAB is unsigned. A separate upload-signed Play bundle is prepared locally with an independent upload key. Store publication, Play-delivered device acceptance and owner-dependent Console declarations remain separate gates.

Release checks, source commit, exact asset inventories and SHA-256 checksums accompany the downloadable artifacts. See `release-manifest.json` and `SHA256SUMS.txt`; deployment status is recorded in `docs/play-store/DEPLOYMENT-1.50.md`.
