# KiCad Visual Review v0.11.2 - drawing navigation fixes

- Selecting a PCB opens its drawing preview instead of an empty Stackup view. View board setup explicitly opens saved setup.
- Boards without a saved physical stackup show their saved layer list and board thickness. Material or dielectric values are not inferred.
- Project folders start collapsed outside the active path, preserve their expansion state, and offer Expand all / Collapse all. Search reveals matching folders.
- Schematic sheet navigation uses compact hierarchy rows with full paths available on hover and actions to open a sheet or locate its parent symbol.

Design files remain read-only. Follow INSTALL.md to reload an unpacked browser installation and refresh GitHub; reload the VS Code window after updating its VSIX.
Local renderer tests and mocked browser transport do not establish live GitHub installation acceptance. All previously documented rendering, connectivity, authentication and compatibility limits remain. See v0.11.1 release notes and LICENSING.md.
