# v0.12.17 — Shared hierarchy and cross-sheet net navigation

The project manager and drawing explorer now use one saved schematic graph. Opening a child in a project containing more than 24 candidates no longer silently leaves the explorer with only that file; bounded parent discovery permits 128 candidates.

- Matching sheet names, nesting and active selection in both trees; referenced missing files remain visible.
- Gold net badges in both hierarchies and Matching sheets buttons in Properties.
- Clicking a marked sheet keeps its related net selected and fits its visible geometry without recreating the viewer or discarding drafts.
- Cross-sheet matching follows saved global labels, explicit global power symbols and unambiguous saved parent-pin / child-label connections.
- Cached sheet matches avoid rebuilding connectivity on repeated UI refreshes. Sender, origin, repository, revision and loaded-path checks isolate hierarchy messages.

See [Sheet navigation](../SHEET-NAVIGATION.md) for an illustrated guide and limits. Reload the extension and refresh repository pages after updating.

## Limits and verification

Only loaded project files are searched. Repeated hierarchy instances, cyclic hierarchical edges, implicit hidden power pins and buses remain unresolved; unrelated local labels do not create cross-sheet matches. Source size and retained-file bounds remain unchanged. Actual browser inspection uses synthetic drawings and mocked local transport; installed extension/private GitHub and Safari acceptance are not claimed.

Local validation passed: 651 JavaScript tests, 64 Python tests with one skip, and browser / VS Code package inventory and security audits. Actual nested browser checks verified shared sheet names, cross-sheet gold badges, preserved net selection after outer-tree navigation, and viewer behavior at a narrower viewport.
