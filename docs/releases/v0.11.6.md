# v0.11.6 — loading recovery and GitHub collaboration

Preview release. Source designs remain read-only.

- File, directory and project metadata reads now use the configured GitHub session account, including session expiry handling. Credentials stay in the worker and are not sent to the raw asset host; authenticated reads reject redirects.
- Rate-limited public file requests have a bounded anonymous raw-content fallback. This requires the new raw.githubusercontent.com host permission. Project metadata, history and search still require API access; reconnect your account or wait for the displayed reset time.
- Project metadata failure no longer prevents opening the requested file. The tree visibly reports incomplete discovery and unpinned branch reads. Source failures end the loading state with the filename and actionable error.
- Large browser PCB reads support up to 64 MiB with bounded parsing and a 96 MiB project budget. Schematic, model and report limits remain separate. Native VS Code and hosted app limits are not raised by this change.
- Dedicated GitHub collaboration tab groups Issue and Discussion destinations, account settings, policy and linked conversations. Notes preserve their thread type in local exports and native sidecars; publication rejects mismatched destinations.
- KiCad legacy footprint reference/value fields populate search, properties and BOM correctly. 3D reports real-model coverage even when no linked models resolve.
- README screenshot gallery, badges, attribution, disclaimers and partial LLM-assisted development disclosure.
