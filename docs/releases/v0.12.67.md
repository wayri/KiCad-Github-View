# Pocket KiView 0.12.67 / Android 1.69 — Firefox submission corrections

This corrective preview includes the 0.12.66 feature set and resolves Mozilla validation findings:

- Saved HTML analysis reads bounded text/table tokens without privileged HTML insertion. Script/resource content remains inert; styling and nested table layout are not reproduced.
- Firefox uses encrypted event-page provider sessions without shipping unsupported Chromium offscreen credential APIs.
- Firefox Android minimum 142 reflects the data-consent API; the store submission remains desktop-only. Desktop minimum remains 140.
- Firefox PDF viewing uses the browser-maintained native renderer and local download fallback, avoiding a modified third-party library. Native PDF controls and rendering limits follow Firefox settings; local/project PDF intake remains capped at 32 MiB. Other platforms retain their existing PDF viewer.

The APK remains a non-debuggable development-signed preview; the AAB is unsigned. GitHub packages, store submission, approval and installed browser acceptance are distinct gates. See the release manifest and Mozilla validation result for verification actually completed.
