# v0.12.27 — Navigation and property polish

The Project/Schematic/Layout header now uses clearer segmented view controls and compact, visually separated actions. Split view indicates its active state. Project setup has more readable labels, values, categories and cards, plus header search across file paths and saved settings. Constraints now honor the saved-settings search. Selection properties have a persistent search for displayed names, values and connections, with matching groups revealed and normal presentation restored when cleared.

Bug fixes: superseded workspace and split discovery can no longer replace a newer view choice or display a stale lookup error. Remote GitHub and GitLab viewers resolve branch names to a commit before loading drawings, companion views, settings and assets, keeping one source revision throughout the review. VS Code local workspaces retain their local source contract.

Validation: regression tests cover delayed discoveries, branch pinning, selected property filtering, and project settings/constraints search. The full release suite and package audits run against the tagged commit. Browser visual checks use production code and fixture transport; they do not establish private-repository authentication or installed-store acceptance. Firefox is unsigned; Safari requires macOS conversion and signing.
