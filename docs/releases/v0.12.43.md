# KiCad Visual Review 0.12.43 / Pocket KiView Android 1.55

This prerelease improves phone review and shares the same inspection tools with
the browser and VS Code extensions. Android uses versionCode 58.

- BoM and assembly use a KiCad-style symbol field grid with field visibility,
  grouping, quantities, custom fields and CSV export. Saved design fields remain
  read-only; procurement drafts and assembly progress stay source/variant scoped.
- All-sheets schematic review displays directional parent-to-child hierarchy
  links separately from net links, preserving saved sheet-instance identities.
- Testpoints have live search, dedicated filtering, source-bound navigation,
  connected-net details and export.
- Returning from calculators, BoM, PDF or Gerber preserves Android's loaded
  drawing, selection and filters instead of reloading it.
- Drawing actions use icons with tooltips and accessible names. Phone menus,
  controls, section headers and spacing are improved; broken punctuation is fixed.
- Project settings and engineering sections use page navigation. Board setup
  presents saved settings in KiCad-style tables; mobile sidebars can be hidden.
- Interactive calculators include circuit diagrams and expanded engineering tools.
- Large Marble layouts avoid a repeated whole-board scan during connectivity
  indexing. Desktop profiling improved; physical Android acceptance is pending.
- Local project collaboration messaging now explains how to connect GitHub or
  GitLab and open a repository on the phone.

The APK uses development signing. The unsigned AAB requires production signing
before Google Play submission. Browser-store/native Safari acceptance and
physical Android acceptance are not implied by build checks. iPhone source and
builds are excluded. Exact package audits and checksums accompany this release.
