# KiCad Visual Review v0.11.1 — project setup UI preview

This preview improves the project settings interface and adds a verified GitHub release process. Schematics and PCB designs remain read-only.

## Changes

- Project setup uses labeled, typed read-only controls and grouped settings instead of raw source-path/value buttons.
- Constraints and net classes use compact forms and tables; source paths remain available for inspection and search.
- Physical stackup retains saved materials, thickness and dielectric properties with a structured table.
- Improved file navigation, spacing, responsive presentation and light/dark themes.
- Branch/PR CI and tag-driven prerelease publication build the exact source commit, run tests, audit package contents and verify SHA-256 checksums.
- Deterministic browser ZIP/VSIX packaging and normalized hosted-viewer/App archives.

## Installation

Download `kicad-visual-review-extension-0.11.1.zip` or `kicad-visual-review-vscode-0.11.1.vsix` and follow `INSTALL.md`. Existing unpacked browser installations need Reload, followed by a GitHub page refresh. GitHub Releases does not install the extension or publish store listings automatically.

The optional `app-web` and `github-app` ZIPs are deployment payloads. They need App registration and an HTTPS host separately; they do not replace the browser extension's inline GitHub interface.

## Verification and retained limits

The release workflow runs all JavaScript and Python suites and package/source audits before publication. Native CLI tests skip where KiCad is unavailable; optional credential tests require the GitHub Python extra. Actions logs and `release-manifest.json` identify the tested commit. Local browser UI verification uses mocked transport and does not establish live installed GitHub or store acceptance.

The v0.11.0 viewing/review features remain available: schematic/PCB hierarchy and properties, highlighting, regex/wildcard search, BOM/variants/DNP, comments, measurements, visual revision comparison, saved ERC/DRC reports, project/stackup/Gerber inspection and isolated HTML previews.

KiCad 11 is a forward preview, not verified support for unreleased features. The renderer is not pixel-identical to KiCad. Rules are displayed rather than evaluated; missing values are not inferred. Zone analytics remain sums of saved polygons rather than exact copper unions. Gerber macros/curved regions/step-repeat/drill slots and STEP models retain their documented limitations. Interactive HTML runs in the browser extension; VS Code provides static HTML previews. Live OAuth/comment publication and github.dev deployment still need separate acceptance.
