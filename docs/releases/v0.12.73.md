# Pocket KiVi 0.12.73 / Android 1.73

Selection outlines use measured text glyph bounds and visible footprint geometry,
including flipped views. Selected nets have stronger visual contrast.

Compact icon-and-text navigation switches schematic, layout, 3D, Draftsman and
Simulation. Existing KiCad workbook/waveform and wayriCAD results remain separate
from the new experimental Fast PI workflow.

Fast PI performs browser-local, fixed-temperature 2.5D DC copper screening from
two selected contacts. It models saved filled zones, straight traces, supported
pads and via/through-hole barrels using reviewed copper stackup and material
inputs. Worker cancellation and operation budgets keep the interface responsive.
A floating results panel reports voltage, drop, current, resistance, copper loss
and current density; gradients, direction arrows and net isolation overlay the PCB.

This is experimental single-net DC screening. Mesh refinement is required;
return-network impedance, AC, temperature feedback and unsupported geometry are
not inferred. See docs/FAST-PI.md for numerical scope and evidence.

Android 1.73/code76 includes the shared capabilities. The APK uses the existing
development signing channel; the unsigned AAB is not a Play Store submission.
Store submission and approval are separate from GitHub publication.
