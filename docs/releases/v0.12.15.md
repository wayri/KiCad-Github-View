# v0.12.15 — Compact comment composer and conversation reader

This release simplifies drawing comments and brings ordinary GitHub conversations into the Comments sidebar.

- Three colored dropdowns select Issue/Discussion, severity and local review state.
- The first comment line supplies the title, including the formatted section published to an existing thread.
- Inline `@` suggestions support mouse selection, arrow keys and Enter. Typed mentions are extracted when saving.
- Paste PNG/JPEG/WebP screenshots directly into the comment box. Conversion is bounded and stale/cancelled conversions cannot change another draft.
- The destination next to **Comment** defaults to New issue. Existing Issue/Discussion destinations accept a thread number; new Discussions expose their category.
- View comments loads ordinary Issue/Discussion messages, authors, dates and Discussion reply relationships. Linked notes provide View thread; Reply prepares a draft without posting.
- A gear menu provides inclusive UTC creation-date filters, alongside existing state, severity, read, search and sorting controls.

## Limits and verification

Conversation reads are read-only, bounded to 200 comments/10 requests and safe text. Private reads require repository authorization; Discussions require sign-in. There is no live subscription or automatic state synchronization. Replies append to a conversation; local review state does not close a remote thread. Screenshot publication needs attachment permissions and retains failed drafts. No live test posts or new installed-browser/Safari acceptance are claimed. Screenshots use actual local rendering with mocked service responses.

Local verification passed: 644 JavaScript tests, 64 Python tests with one skip, and browser/VS Code package inventory and security audits. Browser checks verified inline suggestions, a pasted PNG preview, the posting row, conversation messages and date filtering on local fixtures.
