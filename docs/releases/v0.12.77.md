# Pocket KiVi 0.12.77

- Comment publication no longer reports a failed POST when the provider confirmed acceptance but local receipt/link persistence failed. Repeated destination-dialog restoration is safe. Terms acceptance is retained per installation; later sends to a valid destination proceed directly, with an explicit Destination action to change it. New Discussions require deliberate selection.
- GitHub/GitLab conversations refresh while visible (normally every 3 seconds, with failure backoff); conditional readback and account-bound 30-second permission snapshots avoid unnecessary steady-state reads. Writes still recheck authority. Existing issues/discussions can be browsed and replied to directly.
- Point/area comments retain file/sheet/instance context and millimetre endpoints in validated provider metadata. Locate can use explicit coordinates when object identity is unavailable. Native KiCad field/value tables precede advanced properties. Comments dock toggles closed without discarding drafts.
- Project home emphasizes files, default same-name Schematic/Layout, Calculator and Gerber tools. Settings widgets are created only when requested; returning to an existing drawing preserves its frame.
- Public Ttl/vna2 root/subfolder discovery and old numeric timestamp parsing are covered by retained fixtures. Restricted legacy schematic/cache and PCB module support is available; legacy .brd needs conversion, and KiCad 11 remains unverified forward preview. Saved text variables resolve within bounded metadata; plain drawings avoid the extra project-settings request.
- Assembly variants are directly selectable in the drawing toolbar.
- History / compare displays the GitHub website commit feed with author, date and message. Load an exact commit or compare it with the currently viewed revision. The feed exposes only its initial window (up to 30 commits); older SHAs remain enterable. Project/history reads do not use GitHub REST/GraphQL. Explicit collaboration actions still can.
- Cross-select, Unsplit and Theme are visible workspace actions. Theme commands reach linked detached views. Saved full schematic hierarchy paths and legacy PCB pin identifiers improve cross-selection; ambiguous instances remain rejected.
- Net instances opens a list of occurrences in loaded drawings and up to four movable, independently rotatable miniature viewports. File-tree entries containing highlighted schematic nets are marked.
- Pin/pad labels prioritize full numbers over long net names in 2D and 3D. Drawing tool icons distinguish downloads, native KiCad, Draftsman and Fast PI.
- Experimental browser Fast PI supports modern named nets and legacy numeric IDs, explicit electrical/material inputs, complete saved physical stackup prefills, copper contact validation and voltage/current/density/loss overlays. It is a fixed-temperature 2.5D DC screening model, not a full PI/thermal/AC solver. Unsupported copper constructs are rejected.
- Mechanical Draftsman reuses a single scene and asset inventory across projections and caches local preview PNGs. Its small live SVG preview avoids repeatedly embedding image payloads; downloaded exports retain embedded images. Saved-source invalidation, queued captures and close cancellation are enforced.
- All-sheet hierarchy routes have smaller arrows, rounded bends and thinner muted strokes.

Verification: automated transport, identity, rendering contract, numerical reference and lifecycle checks accompany these changes. Browser-local fixture acceptance is distinct from installed Chrome/Firefox/VS Code and real-repository acceptance. The reported installed GitHub API error was not reproduced in current source and is not claimed universally resolved.

Android 1.77 / version code 80 retains the existing development signing channel. An unsigned AAB needs an upload key before Play submission. Store submission/approval and physical-device installation are separate from package generation.
