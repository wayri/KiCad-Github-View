# Pocket KiView 0.12.65 / Android 1.67 — project dashboard and focused review

The browser extension now has a project dashboard with searchable recent GitHub,
GitLab and local project locations. History stays in extension storage, is bounded
to 50 locations, and can be cleared. Remote entries reopen their saved commit;
local entries explicitly require file reselection. Credentials and project source
contents are not cached by this history.

Review improvements include a cleaner project tree, colour-coded BoM/assembly
progress and grouping, individual part selection, exact pin/pad cross-selection,
close-zoom labels, object/side visibility filters, brighter review colours and grey
context around selections in 2D and 3D. Saved simulation popups and comment anchors
also project into 3D. All-sheet review provides separate hierarchy/net-link
toggles and bounded relationship routing outside sheet content.

GitHub issues/discussions and GitLab issues can close/reopen from the conversation
menu when the provider grants permission. Destination confirmation, policy/source
checks, draft preservation and uncertain-result handling remain in place. Commit
actions include view, compare, download, local copy and remote fork with an exact
selected-commit review branch. Fork default branches are preserved.

Large-board label traversal now stops at its display budget and avoids redundant
pad bounds and intermediate highlight allocations. The retained synthetic
100,000-pad benchmark produces identical labels; measurements describe the CPU
label path with a no-op drawing context, not end-to-end GPU frame rate.

The retained local benchmark measured warm label generation at 395.80 ms before
and 1.17 ms after for the same 300 labels; warm label-overlay work measured
416.17 ms before and 1.42 ms after. Cold spatial-index work still has a cost.

Security review fixed a VS Code fork race: account changes or sign-out now stop
subsequent requests instead of switching credentials mid-operation. Existing
sender, provider, redirect, administrator, source, path and publication protections
are retained. Provider prechecks cannot make remote state mutations atomic.

Limitations: binary SPICE RAW, simulation execution, rendering dimensions and
Altium Rooms are unsupported. Dense relationship graphs may share or cross routes;
routing omissions are identified. 3D anchor projection checks the frustum rather
than performing an occlusion test. Native provider writes were checked with
synthetic transports; no live user issue or repository was changed during tests.

Android 1.67/code70 remains a non-debuggable development-signed preview, with an
unsigned AAB for operator signing. It is not a Play Store production release.
Mozilla submission remains deferred; Firefox/Safari packages retain their stated
development and platform-validation limits.

Release assets are generated and audited against the tagged source, with checksums
and validation evidence in the release manifest. Store submission and physical
device installation are separate from GitHub publication.

Local verification: 1,665 JavaScript checks passed. The Python release suite ran
108 checks with one Windows symbolic-link skip; its licence-contact packaging
mismatch was corrected and the affected six-test package suite passed again.
Both installed KiCad 10.0.6 native export checks passed using its normal config.
Android assemble, lint, unsigned bundle and instrumentation compilation passed.
Desktop/phone browser UI checks covered the dashboard, imported-file tree, BoM,
2D/3D selection, saved-data popup and all-sheet controls. Close/reopen checks used
synthetic provider transports. No physical Android device was available.

The locked npm runtime-dependency audit reported zero advisories. That audit does
not cover every vendored binary or establish security certification. GitHub's
Dependabot-alert endpoint was unavailable because repository alerts are disabled;
this was not interpreted as a clean alert count.
