# Pocket KiVi 0.12.76

Browser GitHub project viewing now reads website repository metadata and raw
project files, without using GitHub REST/GraphQL for project discovery or drawing,
model, settings and report reads. A bounded temporary background buffer shares
immutable public file bytes across viewer windows and avoids repeated downloads.

Default-branch discovery reuses root-page data without confusing a feature-branch
tab with HEAD. Private file reads remain in the signed-in repository tab and are
not retained in the public-file buffer. Scope, cancellation, byte budgets and
partial-inventory diagnostics remain enforced.

Automatic GitHub comment-policy checks and comment polling are removed from
drawing startup. Explicit review/account actions can still use provider APIs.
API-based branch and history lists show website/manual-ref guidance instead.
See docs/GITHUB-WEBSITE-VIEWING.md for cache limits and host requirements.

This change does not add missing 3D libraries to Marble or fix every model-decoder
limitation. Installed-browser 3D and detached-selection acceptance is tracked
separately from automated transport tests.
