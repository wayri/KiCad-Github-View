# KiCad Visual Review v0.12.39 / Pocket KiView Android 1.51

This release brings source-based assembly population highlighting to PCB review and consolidates the portable review tools added since v0.12.38. Android uses versionCode 54 and package `dev.kicadvizdiff.android`.

- Optional PCB highlighting identifies DNP/DNI components from saved source attributes and the selected assembly variant. The overlay is read-only; it does not infer population from photographs or change the design.
- Shared interface proportions improve theme and navigation icons, button sizing, headers and touch targets. Gerber, BoM and assembly use the common panel and toolbar conventions.
- BoM and assembly link part selection to board location, provide clearer population and variant filters, and share local placed/soldered/verified progress with the parts manager. Progress is manually recorded and is not an automated inspection result. Supported iBOM and BoM Studio imports retain source provenance and documented geometry/format limits.
- Gerber review includes a canvas-first layer/analysis panel, anchored zoom and touch controls, unsnapped measurement, configurable geometry screening and source-bound analysis export. Screening does not establish complete manufacturing DFM acceptance.
- Photo/AR review supports saved board alignment, top/bottom photographs and component cross-selection. Reference-based population comparison can assist DNP and variant review; ambiguous observations remain unresolved and physical accuracy requires separate validation. Controlled GitHub discussion drafts can include reviewed inspection logs and photographs.
- Integrated PDF viewing and testpoint tables accompany the existing supported saved WayriCAD analysis overlays, probes and plots, engineering calculators, repository navigation and linked/embedded 3D model handling. Imported analysis does not run or validate the producer's solvers.

The local distribution is a prerelease. The Android APK uses development signing; its release AAB is unsigned. Browser-store publication, Google Play upload signing and Play-delivered device acceptance are separate steps. The earlier signed Android 1.50 Play candidate predates these changes and is not this release.

Build verification, source commit/dirty-checkout status, exact packaged asset inventories and SHA-256 checksums are recorded with the generated artifacts in `release-manifest.json` and `SHA256SUMS.txt`. Preparation of these notes does not itself establish that the new build or runtime checks have passed.

Validation: 76 Python tests and 1,095 JavaScript tests passed, including native KiCad report generation. Android debug APK, lint and unsigned release bundle builds passed. Package inventories and SHA-256 checksums were audited against the source. Desktop and 390 CSS-pixel phone browser checks verified labeled DNP/DNI overlays and selected-variant changes using a retained PCB fixture; installed browser-extension and physical-phone acceptance are not implied.
