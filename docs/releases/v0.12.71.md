# Pocket KiVi browser 0.12.71 — toolbar opens a standalone viewer

Chrome/Chromium and Firefox now share the same toolbar launch flow. Clicking the extension on a supported repository opens a clean extension tab. A single detected KiCad project opens directly; multiple projects show a compact chooser with revision-pinned links. A selected KiCad drawing opens directly in the standalone viewer. Repository landing pages no longer get an injected discovery banner or automatic discovery requests.

Empty repositories explicitly show **No KiCad project detected**. Partial listings disclose possible omissions. Access failures, organization restrictions and failed discovery display a separate error with retry/settings access. Approved GitLab hosts and nested namespaces remain supported; ambiguous branch/folder paths require authoritative page metadata or opening the repository root. From issue/pull-request pages, repository discovery uses the default branch; use Compare commits for revision comparisons.

The launcher has read-only discovery privileges, not comment, account, source-write or native-helper privileges. Existing provider origin checks, administrator policy, source/ref validation and bounded project listings apply. No new permissions are requested.

After updating, reload already-open repository pages to remove their old injected controls. Existing file/PR inline review remains available; toolbar launches no longer focus or navigate the host page. Non-repository clicks open visible no-project feedback with local-files, recent-project and settings links.

The Chrome 0.12.70 submission and VSIX 0.12.70 publication are separate store operations. Android remains 1.72 from v0.12.70, installed on the connected phone. This browser-focused release does not include a replacement Android binary. Firefox remains an unsigned development ZIP while the existing Mozilla listing is disabled pending appeal.

Validation includes action-routing/sender-boundary tests, no-banner content tests, single/multiple/empty/error UI tests, a local browser acceptance run and Chrome/Firefox package inventories. Installed Firefox and live private-provider acceptance are not implied by local tests.
