# Pocket KiView 0.12.63 / Android 1.65 — security hardening

This update carries source-boundary corrections from the October security review across the browser extensions, VS Code, Android and local/hosted viewer distributions. It adds managed network/read-only controls, tighter request admission and authorization, safer Android document selection, bounded report imports and restricted Git inspection.

The loopback services enforce CSP, connection budgets and absolute HTTP I/O deadlines. The hosted GitHub App supports mounted webhook secrets; deployment recipes use a non-root, read-only, resource-limited container behind a restricted ingress. CI actions and build dependencies use pinned identities/integrity checks.

See [hardened deployment guidance](../HARDENED-DEPLOYMENT.md) and [security safeguards](../SECURITY.md). Enterprise controls require administrator configuration; default consumer behavior remains available. These safeguards are not a penetration-test certification. Native KiCad processing still requires OS isolation for untrusted designs.

## Distribution and verification

Android 1.65 (code 68) uses a non-debuggable APK on the existing development-signed distribution channel; it is not a Play production release. Firefox/Safari packages remain development distributions. Signing/provenance and installed-platform coverage are reported in the release manifest and deployment guidance; no untested high-security approval is claimed.

Verification: 1,564 JavaScript tests passed; 108 Python tests ran with zero failures and one Windows symbolic-link privilege skip. Android assembleDebug/lintDebug/bundleRelease/test-APK compilation passed. Installed unpacked Edge and isolated VS Code host smoke checks passed using public/synthetic fixtures. APK/source parity and non-debuggable manifest/signature checks are enforced by the release builder. Phone installation, production signing, Marketplace/Chrome Store upload and Docker/ingress runtime acceptance are separate deployment steps and are not implied by these checks.
