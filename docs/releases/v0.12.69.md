# Pocket KiVi 0.12.69 / Android 1.71 — Draftsman and review workflow

## Draftsman documentation

Create customizable drawing documents in the current viewer tab. Add up to 20 sheets with editable title blocks, paper/orientation, scale, rotation, visible source layers, units, precision, font, line width and accent. Add schematic/top/bottom PCB views, automatic saved-outline dimensions, snapped manual aligned/horizontal/vertical dimensions, notes and paginated fitted-parts BoM tables. Undo/redo, source-bound draft reload, import validation and sheet zoom support continued editing.

Export editable JSON, SVG sheets and a multi-sheet PDF locally. Save to a selected folder where the browser supports directory access. In the browser extension, explicitly confirmed GitHub/GitLab saves create a new documentation branch based on the viewed source commit and can include all three output formats. Administrator write restrictions, account-change checks, bounded payloads and fixed documentation paths apply; the current branch and KiCad design sources are not replaced.

Drawing views are raster previews from the existing renderer. SVG dimensions, annotations and title blocks are vector; PDF is rendered sheet pixels. This is a Pocket KiVi document format, not native Altium/Xpedition document interchange or a manufacturing-certified plot. Repository writes were verified with mocked provider transports, not a live repository commit. See docs/DRAFTSMAN.md.

## Review states and severity

- Open is green, Closed purple and Skipped amber. Linked notes follow the provider issue/discussion's last fetched state; state filters apply to cards, catalogs and thread messages. Skipped is a local profile decision. Close/Reopen provider actions remain permission-checked and explicitly confirmed.
- Five severity levels share one colour scale: Info, Level 1, Minor, Major and Critical. Published review messages include self-contained severity/state banners; they do not silently create repository labels.
- The KiCad local browser composer and extension use the same compact review controls. Saved design sources remain read-only.

## Viewing and navigation

- Persistent Universal 3D lighting provides neutral illumination from all sides; Studio lighting remains available.
- Tilde/backtick/H highlights the pointed net in 2D and 3D. X/Y/Z select positive 3D axis views; Shift+X/Y/Z select opposite views. F flips the PCB, Shift+F fits the view, and schematic F still fits. Text fields, editable content and input-method composition do not trigger these shortcuts.
- Imported KiCad ERC/DRC findings show aligned arrows and compact notes on drawings. On phones, locating a finding closes obstructing results controls. This displays imported reports; it does not run native ERC/DRC solvers.
- The previous full-net 3D and precise comment Locate improvements remain included.

## Packages and channel status

Android 1.71 (version code 74) includes the shared viewer changes. Its APK preserves the development signing channel and is not debuggable. The AAB is unsigned and is not ready for Google Play upload. Draftsman repository writes are currently browser-extension functionality; native-host export support varies.

This release supplies GitHub downloads for Chromium, unsigned Firefox development, Safari development conversion, VS Code VSIX, web, local viewer, Android and supporting source/guides/helper packages. Store signing/approval and GitHub prerelease publication are separate.

Validation includes the full release test gate, source/package byte and inventory audits, Android lint/signature/version checks, and local desktop/phone-viewport browser acceptance for Draftsman, review states and keyboard shortcuts. Installed acceptance on every browser/device and real provider mutations are not implied.
