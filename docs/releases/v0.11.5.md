# KiCad GitHub View v0.11.5 — first public preview

This release publishes the browser extension, VS Code custom editor and optional GitHub App deployment packages for [wayri/KiCad-Github-View](https://github.com/wayri/KiCad-Github-View). It includes the v0.11.4 GitLab.com integration and detailed installation, compatibility and Git comment documentation.

## Browser review

Open public KiCad schematic and PCB files directly inside GitHub or GitLab.com file pages. The browser-only owned rendering engine supports saved part properties, sheet hierarchy/history, net and net-class highlights, project search, layer focus, page/title block inspection, light/dark themes, snapped live measurement and paired schematic/PCB views. SPIKE provides read-only board 3D using repository-linked supported assets. Project views expose saved setup, constraints, layer/stackup tables, BOM/assembly variants, board/zone analytics and fabrication/HTML previews.

GitHub pull-request previews retain file context and use public fork heads. The Git revisions picker compares branches/commits using immutable source revisions and saved-object changes. GitLab.com supports subgroup namespaces and manual branch/commit comparisons; merge-request file cards are not included.

## Review annotations

Notes support part/point/area anchors, severity, tags, mentions, timestamps, read status and Open/Skipped/Resolved/Won't fix metadata. Browser-local notes can be exported, or GitHub viewers can connect a `.kicad-review.json` file in a checkout for normal Git commit/push tracking. GitHub issue/discussion/PR publication is a separate explicit action using a configured token or registered device-flow OAuth client. Public issue/PR marker readback is supported; discussion readback, remote state synchronization and automatic image upload are not.

GitLab notes stay local and exportable. GitLab account connection, remote publication, contributor policy enforcement and review sidecar connection are not implemented. VS Code uses a workspace sidecar without remote publication or native revision comparison.

## Downloads and installation

- **`kicad-visual-review-extension-0.11.5.zip`**: extract, enable Developer mode in `chrome://extensions` or `edge://extensions`, then **Load unpacked** the folder containing `manifest.json`. Allow supported sites and refresh the repository page.
- **`kicad-visual-review-vscode-0.11.5.vsix`**: install using **Extensions: Install from VSIX** and reload VS Code.
- **app-web / github-app ZIPs**: optional hosted viewer/service payloads; App registration and HTTPS hosting are separate.
- **`INSTALL.md`, `COMMENTS.md`, `GIT-HOSTS.md`**: installation, annotation/GitHub workflow and service matrix.
- **`SHA256SUMS.txt`, `release-manifest.json`**: verified package inventories, hashes and source commit evidence.

See [the README](https://github.com/wayri/KiCad-Github-View#readme), [installation](https://github.com/wayri/KiCad-Github-View/blob/v0.11.5/docs/INSTALL.md), [comment guide](https://github.com/wayri/KiCad-Github-View/blob/v0.11.5/docs/COMMENTS.md) and [host compatibility](https://github.com/wayri/KiCad-Github-View/blob/v0.11.5/docs/GIT-HOSTS.md).

## Compatibility and release status

Chrome/Chromium is the primary desktop extension target; Edge uses the same package. Brave and other Chromium browsers are candidates requiring separate validation. Firefox, Safari and mobile packages are not shipped. Browser-store and VS Code Marketplace listings are not published.

Browser previews support public GitHub.com and GitLab.com only. Private repositories, self-hosted instances, GitHub Enterprise, Bitbucket, Azure DevOps, Gitea and Forgejo adapters are pending. Local VS Code files are independent of the remote Git host.

Designs remain read-only. Browser fonts and some constructs are approximate/incomplete, full instance/cross-sheet connectivity is unresolved, native ERC/DRC is not run, and saved-object comparison is not electrical equivalence. KiCad 9/10 recognized constructs are covered; KiCad 11 headers are forward previews, not full compatibility certification. STEP models and some Gerber/drill constructs remain unsupported. Local tests and mocked browser fixtures do not establish live installed-browser or store acceptance.
