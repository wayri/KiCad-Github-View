## Verification and limits

[Marble browser acceptance and screenshots](../QA-LAYER-HIGHLIGHTS-0.12.89.md) use the full 44.1 MB public PCB at revision a426777d92c0f22a546d4740b419a3937e0c1f90. Layout and 3D, both probe types, Accent/Layer colors switching, popup zoom and rotation passed in the integrated browser through the production viewer with locally buffered saved source. No script errors were recorded. This does not establish installed-store or physical-device acceptance.

External Marble component models were not supplied for this test; the 3D captures show footprint proxies. Saved-geometry diagnostics and rendering budgets still apply, including omitted unsupported pads and some zone/drill geometry. Layer coloring does not repair absent source geometry. See the acceptance report for details and source attribution.

Source gates passed: all 2,410 JavaScript tests; 149 of 150 Python tests, with one Windows symbolic-link privilege skip. The Android Java boundary regression passed separately with the installed JDK.

Altium beta is excluded. Android APK uses the existing development signer and is non-debuggable; the unsigned AAB is not ready for Play Store upload. GitHub publication and store submissions are separate.
