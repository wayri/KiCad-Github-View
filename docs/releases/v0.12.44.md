# KiCad Visual Review 0.12.44 / Pocket KiView Android 1.57

This prerelease brings the KiCad-style field grid to the drawing BoM manager,
matching the imported BoM and assembly viewer on phone and extension. Android
uses versionCode 60.

- The drawing BoM remains a table on phones, with fixed headers and reference
  column, horizontal scrolling, field visibility and custom saved fields.
- Group by presets cover Value, Footprint, Value + footprint, Rate (unit price)
  and Custom fields. Custom checkboxes support multiple grouping fields.
- Numeric rates such as 1 and 1.00 group together. Currencies, absent prices,
  zero prices, DNP/exclusion states and saved source identities remain distinct.
- CSV export follows the displayed columns and grouping. Differing values are
  marked mixed; group management edits preserve fields that were not changed.
- Compact controls and statistics leave more room for the field table. Existing
  source navigation, procurement drafts and assembly progress remain available.

Android 1.57 was installed on the connected Samsung phone. The new grid and
grouping controls were checked in a phone-size browser preview; Marble's new
on-device BoM acceptance remains pending. The previous 1.55 device test loaded
Marble and its 1,006 footprints successfully.

The APK is development-signed. The AAB is unsigned and requires production
signing before Play submission. Browser-store and native Safari acceptance are
not implied by these packages. iPhone source and builds are excluded. Package
audits, the source commit and SHA-256 checksums accompany this release.
