# v0.12.20 — Root schematic navigation and three-tab workspace

The primary workspace uses one row: **Project · Schematic · Layout · Split view · Compare commits**. Project contains source settings, constraints, stackup and fabrication tools. Drawing frames remain mounted when switching tabs, retaining camera position and review drafts. Split options are tucked into a menu.

- Ordinary schematic entry opens the unique saved root, even when the requested file is a subsheet. Navigate using the hierarchy tree, double-click a sheet symbol, or use the top Back / Forward / Up / Root controls.
- GitHub and GitLab schematic discovery uses bounded repository inventories and saved relative paths, including nested folders, sibling folders and `../` references. The project tree receives the same hierarchy and highlighted-sheet state as the drawing explorer.
- Explicit change-position links keep their requested subsheet while Root still navigates to the actual saved root.
- GitHub revision resolution reads only the SHA media response and small Git commit metadata, avoiding large diff/patch payloads during schematic loading.
- Ambiguous roots, cycles, unavailable sources and truncated or oversized inventories have visible diagnostics. No root is guessed. Discovery is limited to 128 schematic candidates / loaded hierarchy files and 96 MiB project source.
