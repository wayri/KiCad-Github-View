# v0.12.7 - Authorized private PR comparison

Private GitHub pull requests and source forks can be compared with a connected account that has access to the involved repositories. The inline Files changed viewer no longer rejects authorized private metadata.

Merge-base comparisons use immutable base/head commit SHAs instead of a moving PR ref. The response must confirm both requested commits. File pagination retains the same account through bounded streamed requests and verifies base/head/count before and after fetching up to 3,000 files. Changed PRs, incomplete listings, revoked access and sign-out abort instead of returning a mixed snapshot. Fork identity stays attached to head drawings and model reads; deleted source metadata is rejected.

Tests cover private forks, inline mounting, pagination, pinned revisions, authentication races and incomplete lists. Provider tests use simulated responses; no live private PR or installed browser was used. GitHub Enterprise remains unsupported. Existing rendering and browser-port limitations still apply. The README is normalized to UTF-8.
