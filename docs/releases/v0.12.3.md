# v0.12.3 — Native Git and Actions review coverage

The optional GitHub Actions review now includes deleted drawings and detected renames, preserving the old path for the base revision. PCB and schematic reports retain their original extensions, preventing same-basename collisions. An HTML index links successful reports, identifies rendering failures and states when no drawings changed. `review.json` records immutable base/head commit IDs, source paths, Git change status, output paths and rendering success.

PR runs compare the merge base to the head commit rather than comparing against a base branch that may have advanced. Manual dispatch accepts explicit base/head revisions and compares them directly. The workflow keeps read-only permissions, disables persisted checkout credentials, runs native acceptance checks after installing KiCad, and uploads completed reports even when a drawing fails. Changed-drawing count is bounded to 256.

Native schematic comparison pairs renamed pages using matching saved hierarchy identities and updates the associated properties/navigation metadata. Ambiguous identities or page collisions are left unmatched rather than guessed. Legacy `Sheet file` and `Sheet name` properties now work in native report inspection as well as the browser viewer. The composite action exposes `old-file` for renamed drawings.

Original synthetic schematic hierarchy and PCB examples are included under `examples/sensor`, together with a detailed Actions integration guide. They demonstrate rendering and review, not electrical validation or fabrication readiness. Native tests exercise real Git commits and the installed KiCad exporter; report comparisons are not ERC/DRC or electrical-equivalence evidence.

This retains v0.12.2's GitHub account button, connection indicator, background authorization polling and repository access diagnostic. Firefox remains an unsigned development package; Safari needs macOS conversion/signing. Browser rendering fidelity and unsupported model/connectivity limits remain unchanged.
