# Pocket KiView 0.12.82 / Android 1.82 — preview

Preview packages use browser/VS Code version **0.12.82**, Android **1.82**, version code **85**. Store approval and phone installation are separate from a GitHub preview release.

## Review conversations and drawing locations

- Existing GitHub Issue conversations can be read through the explicitly connected repository website session, independently of the optional review-account connection. The development transport sends replies through GitHub's own loaded composer. It does not add broad repository OAuth access, export website credentials or bypass organization policy.
- Corrected Issue reply timestamp handling for GitHub's `lastEditedAt` field. An unedited reply uses its saved creation time. Previously, requiring `updatedAt` on every reply could reject readback after a successful post.
- Drawing metadata read from Issue bodies and replies restores numbered point markers and rectangular areas on the matching schematic or layout. PCB locations also project into 3D on their saved board side. Rotated areas preserve all four corners.
- Clicking a drawing marker opens its linked conversation. Refreshing one Issue preserves other Issues' markers. Incomplete snapshots retain known locations; a complete selected-thread snapshot can remove its deleted annotations.
- A bounded website listing scan reads at most eight Issues, with a 30-second annotation snapshot cache and 60-second listing cache. Coverage warnings disclose omitted Issues or comments. Ordinary messages without saved drawing coordinates remain in the conversation rather than gaining invented positions.

## Acceptance and limitations

Browser-session Issue readback was exercised independently of the optional extension review account. Focused tests cover provenance, exact file/revision matching, explicit publication, duplicate protection, timestamp compatibility, marker retention and area projection. No private project content or screenshots are included as release evidence.

The isolated synthetic browser fixture verified imported markers and areas in schematic, layout and 3D, marker-to-thread navigation, rotated schematic areas and Locate focus. This is renderer/UI evidence, not a claim of live provider authentication in that fixture. All 2,343 JavaScript tests passed. Release assembly records the Python and package-audit results separately.

Live GitLab, Firefox, Android and VS Code acceptance of this browser-session GitHub transport is not established. New Issues, Discussions, state changes and attachments are outside the existing-Issue website-session beta. Existing provider-connected capabilities have separate coverage.

## Other viewer improvements

- Optional in-page project viewing remains an explicit user choice; ordinary toolbar opening uses a separate viewer tab.
- Improved foreground repository/session discovery, private model-path handling and recoverable access diagnostics, with no required broad repository permission for browser project viewing.
- Expanded Gerber, drill and job-file discovery and viewing. Supported drill/routing commands retain their source units and format diagnostics; unsupported constructs are disclosed rather than silently converted.
- Refined all-sheet hierarchy/tree navigation, settings controls and copper depth precision. No claim of complete all-board, all-format or all-GPU compatibility is made.

The Altium experiment remains local-only and is excluded from release payloads.

The Firefox ZIP is unsigned and requires developer installation or Mozilla signing. The Android APK is development-signed and non-debuggable; its AAB remains unsigned and is not a Play Store release.
