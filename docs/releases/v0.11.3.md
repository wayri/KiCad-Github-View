# KiCad Visual Review v0.11.3 - sheet navigation

The schematic sheet browser now provides Back, Forward, Up and Root controls with matching icons. Alt+Left/Right navigate sheet history, Alt+Up opens a parent, and Alt+Home returns to the loaded root. Sheet visits from drawing selection, search and hierarchy navigation join the same bounded history; new navigation after Back replaces the forward branch. Text entry is unaffected by these shortcuts.

Root discovery follows saved loaded parent links, including when the viewer initially opens a child. Ambiguous or cyclic roots are not guessed. Viewers remain read-only and previous rendering and connectivity limitations remain unchanged. Reload the browser extension and refresh GitHub, or reload VS Code after installing the updated VSIX. Live GitHub and store acceptance are not implied by local browser verification.
