# v0.11.9 — encrypted authentication and cleanup

GitHub tokens are encrypted with AES-256-GCM and a non-extractable key held only in background memory. Stored expiry is authenticated, sessions are capped at eight hours, legacy plaintext is purged, and corrupted or copied records fail closed. OAuth device secrets remain in background memory. Read transports now obtain authentication through the privileged credential helper.

Sign-out deletes credentials and cancels pending sign-in with protection against late responses. **Reset GitHub connection** also removes a custom OAuth client ID while preserving notes. Settings include links to revoke OAuth access or manual tokens on GitHub.

Background suspension/restart now requires reauthentication; Chromium can suspend the worker after ordinary idle periods. Uninstall removes local extension storage but does not revoke authorization on GitHub. Encryption protects copied storage, not bearer tokens stolen after decryption or a compromised running browser/OS. See SECURITY.md for the threat model and verification limits.

Browser-only OAuth still needs the publisher's registered public Client ID. Firefox remains an unsigned development package; Safari requires macOS conversion, signing and runtime verification. No live authorization or remote comment was created during these security checks.
