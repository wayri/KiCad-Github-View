# v0.12.19 — KiCad-style controls and store deployment guide

The shared schematic and PCB viewer now separates top view/navigation controls from a vertical inspection tool strip. Measurement, grid, board flip, 3D, saved ERC/DRC results, view settings and canvas theme share a stable side strip. Floating comments and properties leave that strip accessible.

- Compact, readable top controls and clearer active states, with larger navigation and property text.
- Independent canvas theme toggle: pressing D changes the drawing theme while retaining the interface theme.
- Explicit KiCad, dark, light and custom display presets. KiCad uses a light interface with a light schematic or dark PCB canvas.
- View settings prioritize display preferences. Drawing-sheet overrides are collapsed until needed; Escape closes settings and returns focus to the toolbar.
- VS Code package includes the project PNG icon, repository/homepage/support metadata and absolute documentation links.
- [Store publishing guide](../STORE-PUBLISHING.md) gives exact Chrome Web Store and Visual Studio Marketplace upload steps, reviewer testing and remaining privacy/licensing readiness decisions.

This is a read-only KiCad-inspired review interface. Native editing tools are unavailable. Store developer accounts, agreements, registration fees and actual listings require the publisher's action; this release does not submit either store listing.
