# Pocket KiVi 0.12.70 — Draftsman templates, snapping and user guide

The first Draftsman workspace shipped in 0.12.69. This update adds an alternative KiCad-style worksheet with double boundary, coordinate zones and a divided title block. Modern remains the default for existing documents. The alternative preserves saved schematic colours; custom `.kicad_wks` worksheets are not interpreted.

Compact icon controls retain descriptive accessible names and tooltips. Manual dimensions snap to saved hole/circle centres, corners, endpoints, straight edges and rounded edges. A visible cursor cue identifies the target and source coordinates. Alt temporarily bypasses snapping, Shift constrains the second point, and touch supports drag-preview/release placement. The indexed geometry lookup avoids scanning the full drawing on every pointer movement. Hidden geometry and frame/text primitives are excluded.

The illustrated GitHub user guide now includes a five-minute introduction, current download/support links and a Draftsman workflow with an application-only source-preview screenshot. Captures identify synthetic fixture/provider data and do not imply live repository publication or physical-device acceptance.

PDF, SVG and editable document exports, outline dimensions, title blocks, notes, fitted-parts BoM and explicitly confirmed new-branch repository saves remain available. Saved KiCad design sources stay read-only. Drawing views are raster previews, SVG annotations are vector, and PDF contains rendered sheet pixels.

Android 1.72 (version code 75) includes the same template, compact controls and snapping refinements. The APK retains the existing development signer and is not debuggable. The AAB is unsigned and is not ready for Play upload. GitHub packages, Marketplace verification and browser-store review are separate channels. Firefox is an unsigned development package; the existing Mozilla listing remains disabled pending its appeal. Safari requires native conversion/signing.

Validation: focused geometry/template tests, the full release test gate, exact package/source audits and local desktop/phone-viewport Draftsman editing/export acceptance. Provider writes use mocked transports; live account writes and every installed device/browser are not certified by these checks.
