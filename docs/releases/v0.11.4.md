# KiCad Visual Review v0.11.4 - GitLab.com previews

The browser extension now embeds schematic, PCB and project viewers in public GitLab.com repository file pages, including subgroup namespaces. The shared viewers retain sheet navigation, parts/properties, net highlighting, project search, saved reports and repository-linked model loading. Branch/commit comparison preserves the Git host and resolves immutable source revisions.

GitLab transport uses a separate bounded, unauthenticated API adapter. Sender validation permits only explicitly supported hosts. GitLab local notes and read receipts are isolated from GitHub notes and credentials; GitHub account, publication and review-sidecar controls are hidden in GitLab viewers. Notes can be exported and committed manually.

GitLab private repositories, OAuth/login, remote issue publication, merge-request file cards and self-hosted instances are not included. Other providers are not implemented. See [Git host compatibility](../GIT-HOSTS.md). Existing read-only rendering and connectivity limitations remain unchanged.

Reload the Chrome/Edge extension and refresh the repository page to apply the new GitLab.com site permission. Install the matching VSIX and reload VS Code for the shared viewer updates. Local transport tests and browser fixture checks do not establish live installed GitLab extension acceptance. Store publication and external deployment remain separate.
