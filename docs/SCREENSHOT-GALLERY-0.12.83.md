# Capability screenshot gallery — 0.12.83

[Demo board acknowledgements and source revisions](DEMO-BOARD-CREDITS.md) — thanks to OLIMEX, Berkeley Lab Marble, Ttl/FMCW3 and KiCad demo contributors.

**123 screenshots**: 67 fresh captures plus explicitly versioned historical evidence. Captured 4 November 2026.

[Open the searchable visual gallery](SCREENSHOT-GALLERY-0.12.83.html) · [Every documented capability and gaps](CAPABILITY-SCREENSHOT-COVERAGE-0.12.83.md) · [Fresh capture manifest](images/0.12.83/capabilities/capture-manifest.json)

Fresh images use the audited 0.12.83 browser package with retained public Olimex ESP32-PoE M2 sources and models, or named public QA fixtures. No private organization content, account credentials, taskbar or Android status bar is included. Local browser transport is not installed-extension or physical-device acceptance. Saved wayriCAD files are fixture data; the new Fast PI strip results are an actual browser solve.

**Coverage is not complete:** provider authentication/posting/reverse sync, private organization access, physical device/foldable behavior, photo detection, presentation, remote saves, and security guarantees are not established by this gallery. The coverage table lists unpictured, partial and unsupported claims explicitly. Older pictures are not relabelled as current.

The supplied offline ZIP preserves these paths and includes this HTML/Markdown index and provenance. Screenshots show actual UI; they are not generated product mockups.
