# Rebuilding the STEP kernel for extension CSP

The pinned-source Windows build and no-dynamic-code conversion regression passed on 2026-10-04. Distribution also requires the browser worker and complete release gates. Cross-platform and bit-for-bit reproducibility have not been established.

Use the pinned importer and OCCT tarballs from the corresponding-source companion. Unpack the importer contents directly as `.vizdiff/step-src/`, with its CMakeLists.txt at that directory root. Unpack the OCCT contents under `.vizdiff/step-src/occt/`; verify `occt/src/TopoDS/TopoDS_Shape.hxx` exists. An empty submodule directory from the importer archive is not OCCT source. Short source paths avoid Windows' 32,767-character process command limit.

Install the official Emscripten SDK as `.vizdiff/emsdk` and run `emsdk install 3.1.69`. Install Ninja into `.vizdiff/step-buildtools` using `python -m pip install --target .vizdiff/step-buildtools ninja`. Use CMake from your normal tool installation. Run `scripts/rebuild_step_csp.cmd` from this project's root. It activates the SDK only in that process, sets the Release build and `-sDYNAMIC_EXECUTION=0`, and uses four parallel compiler jobs. The importer and OCCT sources are unchanged. Windows Ninja response files are enabled; the shortened source paths are still needed because this Emscripten version expands response-file arguments before launching Clang.

The output pair is `.vizdiff/csp-step-build/short-output/Release/occt-import-js.js` and `.wasm`. Before replacement, record both SHA-256 digests, tool versions and the pinned source revisions in `extension/vendor/occt/NOTICE.md`. Preserve both upstream licenses, the OCCT exception and Emscripten runtime license. Replace the JavaScript/WASM pair together, then run `python scripts/build_step_worker.py`, `node scripts/build_spike_bundle.mjs` and the complete release gates. The blob-worker bundle must match its sources; the VS Code packager rejects a stale bundle.

The corresponding-source companion includes the original importer and OCCT archives, this recipe, the worker bundle builder and licenses. For a portable/Linux build use the same CMake Release and `-sDYNAMIC_EXECUTION=0` flags with Emscripten 3.1.69; that path has not been independently verified.
