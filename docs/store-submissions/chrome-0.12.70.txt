NAME
KiCad Visual Review for GitHub and GitLab

SHORT DESCRIPTION
Browser-only KiCad schematic and PCB review on GitHub, GitLab.com and configured GitLab servers, with issue comments.

WHAT'S NEW — 0.12.70
- Add a KiCad-style worksheet template alongside Modern, with page boundary, coordinate zones and divided title block. Custom .kicad_wks templates are not loaded.
- Use compact Draftsman icons, visible snap cues, mounting-hole/circle centres, corners, straight and rounded edges for manual dimensions. Alt bypasses snapping, Shift constrains, and touch supports drag-preview/release placement.
- Read the refreshed illustrated GitHub user guide, including first-run and Draftsman workflows.
- Retain 0.12.69 multi-sheet PDF/SVG/editable exports, confirmed documentation-branch saves, review states/severity, universal lighting, shortcuts and imported ERC/DRC markers. Drawing views and PDF are raster output; SVG annotations are vector. Native solvers are not run.

DETAILED DESCRIPTION
View and review saved KiCad schematics, PCB layouts and supported 3D models without leaving supported GitHub or GitLab repository pages. Open local drawings and folders from the extension, or use its project dashboard to revisit recently accessed projects.

The dashboard keeps up to 50 project locations locally in the extension. Remote entries reopen their saved revision. Local entries require file reselection: history does not cache source contents or credentials. Search, filter, remove or clear recent entries.

Inspect parts, pins/pads, nets and saved properties; search the project tree; compare saved revisions; and cross-select related schematic, layout and 3D objects. Selected geometry stays coloured while the surrounding drawing greys out. Object-type and top/bottom visibility filters, close-zoom pad/net labels, copper-layer controls and measurements help focus a review. All-sheet mode puts loaded schematic pages on one canvas, with optional routed hierarchy/net relationships and repeated-sheet stacks.

Review the BoM with grouping, assembly/procurement status colours and a local assembly checklist. Read supported saved simulation workbooks, exported samples and reports. Saved-data inspection does not run a simulation or native KiCad ERC/DRC solver.

Create revision-bound Draftsman documents with local PDF/SVG/editable exports and optional confirmed repository saves to a new branch. Documents retain source fingerprints; no KiCad design file is modified.

Use project-linked comments and provider conversations, with mentions, screenshots, drafts and destination review before posting. Close/reopen GitHub issues/discussions or GitLab issues when provider permissions and administrator policy allow. Commit actions include viewing, comparison, project ZIP download, independent local copies and confirmed remote forks with a branch at the selected commit.

Large-board label optimizations reduce redundant work. Results vary by board size, hardware and browser; synthetic CPU measurements are not GPU frame-rate guarantees. Missing or approximate model geometry remains identified.

Public repository viewing can work without an account, subject to provider access and rate limits. Private access and publishing require provider authorization and sufficient rights. Organization policies can restrict these features. Local drawings remain available without remote authentication. This extension is not affiliated with KiCad, GitHub or GitLab.
