# Repository STEP preview (development)

The browser development build resolves saved relative or mapped STEP/STP links and tessellates them in a dedicated worker with Open CASCADE WebAssembly. Models are fetched through the same authenticated, bounded repository asset route as WRL/GLB, not from arbitrary URLs. Saved footprint translation, rotation, scale, population and board-side transforms apply to the resulting geometry.

Limits: 8 MiB per model, 30 seconds per conversion, 512 meshes and 500,000 vertices/triangles total. The worker can be terminated on timeout or viewer closure; the input/output limits do not establish a strict bound on temporary native tessellation memory. All output coordinates are millimetres. Mesh-level colors are retained; individual face colors are not yet preserved. Missing/unsupported models retain explicitly identified proxies. Local model paths and custom environment variables require repository mappings.

Verification on 2026-10-04: the hand-authored 300 mm cube fixture produces 12 triangles with 0–300 mm bounds on each axis. A pinned-source Emscripten 3.1.69 rebuild with `-sDYNAMIC_EXECUTION=0` passes actual conversion in a Node VM that prohibits dynamic JavaScript construction. The actual browser/SPIKE blob-worker path under inherited CSP loads its scaled 6 mm repository model, reports real geometry for 1/1 footprints, and logs no errors. Transport was mocked locally; this does not prove an installed extension/private-host workflow or final visual fidelity. The final inherited-CSP check also captured the linked cube rendered above its board; the retained local evidence is `.vizdiff/step-csp-browser.png`.

Marble's retained repository tree contains no STEP/STP/WRL assets. Its `${CERN}` paths remain unresolved; this decoder does not make those absent libraries available. The development VS Code bridge now accepts bounded STEP assets and packages a blob worker with extension-only resource access, and the rebuilt importer passes the inherited-CSP browser check. The actual native VS Code host smoke opens schematic/PCB editors, loads two sheets, persists/reopens a review note and reads the repository STEP asset without altering design sources. Native webview 3D visual inspection and installed browser runtime acceptance remain pending. Firefox/Safari package generation is verified separately from their installed runtime acceptance.

Distribution: importer 0.0.23 rebuilt from unchanged pinned sources, pinned source revisions and binary hashes are recorded in [the dependency notice](../extension/vendor/occt/NOTICE.md). The release builder includes a checksum-verified corresponding-source companion. The Windows rebuild recipe passed; cross-platform and bit-for-bit reproducibility remain unverified. This preview is included in v0.12.8; it retains the acceptance limits described above.
